Estilos de interação:
WIMP e manipulação direta

Todo sistema interativo estabelece uma "linguagem de comunicação" entre o usuário e a máquina. Essa linguagem define o que o usuário precisa saber, o que ele precisa lembrar e como o sistema responde às suas ações. Entender os diferentes estilos de interação é fundamental para escolher o modelo mais adequado ao público, ao contexto e à tarefa.

O que é um estilo de interação?

Um estilo de interação é o conjunto de mecanismos que define como o usuário comunica intenções ao sistema e como o sistema responde. Ele determina a sintaxe da conversa humano‑máquina: os "verbos" que o usuário pode usar e a "gramática" que rege essa troca.

A escolha do estilo impacta diretamente a curva de aprendizado, a velocidade de execução, a carga de memória exigida do usuário e a flexibilidade que o sistema oferece. Não existe estilo universalmente superior — o mais adequado depende do perfil do usuário, da tarefa e do contexto de uso.

Conceito central: Shneiderman & Plaisant (2010) identificam que os estilos de interação diferem fundamentalmente na proporção entre reconhecimento (o usuário vê opções disponíveis) e recordação (o usuário deve lembrar comandos de memória). Interfaces que exigem mais recordação são mais poderosas para especialistas, mas mais hostis para iniciantes.

Os seis estilos clássicos de interação

A literatura de IHC reconhece seis estilos principais, que podem coexistir na mesma interface — muitos sistemas modernos são híbridos.

Linguagem de comando (CLI)

O usuário digita comandos de texto. Requer memorização, mas oferece alta velocidade e expressividade para especialistas. Ex.: terminal Unix, Git, SQL.

WIMP / GUI

Janelas, ícones, menus e ponteiro. Reduce a carga de memorização usando reconhecimento visual. Base das interfaces de desktop desde os anos 1980.

Menu e formulário

Listas de opções visíveis e campos estruturados. Limitam o espaço de escolha — reduzindo erros — em troca de velocidade para especialistas.

Manipulação direta

O usuário age diretamente sobre representações visuais dos objetos (arrastar, redimensionar, tocar). Intuitivo e com feedback imediato. Ex.: Figma, apps mobile.

Linguagem natural

Interação em linguagem cotidiana — escrita ou falada. Amigável para novatos, mas ambígua e difícil de processar com precisão. Ex.: chatbots, Siri, ChatGPT.

Voz, gesto e multimodal

Combinação de canais (voz, toque, movimento, olhar). Crescente com wearables, XR e assistentes de voz. Reduz a necessidade de dispositivos físicos.

WIMP em detalhe

O acrônimo WIMP — cunhado por Merzouga Wilbert em 1980 — descreve o paradigma dominante em interfaces de desktop por quatro décadas. Cada elemento tem uma função cognitiva bem definida:

W
Windows · Janelas

Regiões da tela que isolam contextos de trabalho. Permitem multitarefa visual, mas exigem gerenciamento de foco e podem causar fragmentação da atenção.

I
Icons · Ícones

Representações pictóricas de objetos e ações. Usam a memória visual para reduzir a carga textual — mas dependem de convenção cultural para serem compreendidos.

M
Menus

Listas de ações disponíveis. Tornam o espaço de possibilidades visível (reconhecimento em vez de recordação), mas podem ficar profundos demais em hierarquias complexas.

P
Pointer · Ponteiro

Dispositivo de apontamento (mouse, trackpad, dedo). Liga o mundo físico ao virtual e torna a seleção direta. A precisão do ponteiro afeta diretamente a eficiência (Lei de Fitts).

Exemplo
Quando você abre o VSCode, você está num ambiente WIMP: cada arquivo abre em uma aba/janela, o explorador usa ícones de pasta, comandos são acessíveis via menus e você navega com o ponteiro. Ao mesmo tempo, a paleta de comandos (Ctrl+Shift+P) injeta CLI dentro do WIMP — um híbrido clássico.

Como chegamos aqui: breve linha do tempo

1945–1960s
Cartões perfurados e batch processing. Nenhuma interação em tempo real — o usuário submetia um "lote" de instruções e aguardava o resultado horas depois.
1960–1970s
Terminais de texto (CLI). O usuário digita, o sistema responde linha a linha. Pioneiros como o UNIX tornam o computador interativo, mas exigem treinamento extenso.
1973–1984
Xerox Alto e Apple Lisa/Mac. A primeira GUI comercialmente relevante aplica o paradigma WIMP, democratizando o acesso ao computador pessoal.
1990s
Web e hipertexto. O link como elemento de interação muda o paradigma: clicar em texto e imagens como forma de navegação entre documentos.
2007–hoje
Touch e pós-WIMP. O iPhone populariza a manipulação direta por toque. Gestos substituem o ponteiro; o mouse deixa de ser obrigatório. Voz, AR e XR expandem ainda mais o repertório.

Manipulação direta: o estilo mais intuitivo?

Ben Shneiderman (1983) cunhou o termo manipulação direta para descrever interfaces em que o usuário age sobre representações visíveis dos objetos de interesse, com feedback imediato e reversível. É o estilo que mais se aproxima da interação com objetos físicos do mundo real.

Os três princípios originais de Shneiderman são:

  • Representação contínua dos objetos e das ações disponíveis — o estado do sistema está sempre visível, sem necessidade de memorizar o que existe.
  • Ações físicas em vez de sintaxe complexa — o usuário clica, arrasta, redimensiona, ao invés de digitar comandos.
  • Feedback rápido, incremental e reversível — cada pequena ação produz uma resposta imediata; erros podem ser desfeitos com facilidade.

Exemplo concreto: No Figma, você vê os elementos na tela, arrasta para mover, puxa as alças para redimensionar e vê o resultado em tempo real. Não existe sintaxe textual para aprender — o mapeamento entre ação e efeito é natural. Isso é manipulação direta pura.

Vantagens e limitações

Vantagens
  • Curva de aprendizado baixa para novatos
  • Feedback imediato reduz erros
  • Ações reversíveis aumentam a confiança do usuário para explorar
  • Mapeamento natural com o mundo físico
  • Alta satisfação subjetiva
Limitações
  • Demorado para tarefas repetitivas (arrastar 500 arquivos)
  • Exige coordenação motora (problemático para usuários com deficiência)
  • Ocupa muito espaço de tela (menos denso em informação)
  • Difícil de automatizar ou criar macros
  • Pode esconder funcionalidades avançadas

Quando usar cada estilo?

A escolha do estilo deve ser guiada pela análise do usuário (novato, especialista, frequência de uso), da tarefa (complexidade, repetição, precisão) e do contexto (ambiente físico, dispositivo, conectividade).

Estilo Melhor para Evitar quando
CLI Especialistas, tarefas repetitivas, automação, poder expressivo Usuários iniciantes ou de uso esporádico
WIMP / GUI Usuários casuais, múltiplas tarefas simultâneas, desktop Telas muito pequenas, usuários cegos (sem adaptação)
Menus Limitar escolhas, reduzir erros, onboarding Especialistas que precisam de velocidade; hierarquias muito profundas
Formulários Coleta estruturada de dados (cadastro, pedidos) Conversas abertas, tarefas exploratórias
Manipulação direta Edição visual, desenho, mobile, usuários leigos Tarefas muito repetitivas; usuários com limitação motora
Linguagem natural Assistentes, busca, suporte ao cliente, acessibilidade Precisão crítica; ambiguidade inaceitável

Atenção ao design híbrido: sistemas maduros combinam estilos. O Google Docs é WIMP + formulários + linguagem natural (busca). O GitHub Desktop é GUI sobre operações Git que também existem como CLI. Projetar bem um híbrido significa não esconder uma camada da outra — usuários avançados precisam chegar ao CLI sem ter que desinstalar a GUI.

Tendências pós-WIMP

O termo pós-WIMP descreve paradigmas de interação que vão além do modelo janela/ícone/menu/ponteiro, especialmente aqueles que não dependem de teclado e mouse.

Interfaces de toque (touch)
Gestos multipoint (pinch, swipe, rotate) substituem o ponteiro. A manipulação direta atinge seu ápice com a tela como superfície de ação. Desafio: affordances são menos visíveis — o usuário precisa descobrir gestos.
Interfaces de voz (VUI)
Alexa, Siri e Google Assistant popularizaram a interação sem tela. Funciona bem para comandos simples, mas é frustrante em tarefas complexas ou ambientes ruidosos. Dependente de linguagem natural — e de boa documentação dos comandos disponíveis.
Realidade Aumentada e Virtual (AR/VR)
O usuário interage com objetos 3D no espaço físico ou virtual. Novos vocabulários de interação surgem: olhar (gaze), gestos no ar, controladores físicos. Ainda em fase de padronização — cada fabricante define seus próprios padrões de interação.
Interfaces tangíveis (TUI)
Objetos físicos como interfaces: manipular peças físicas que mapeiam para dados digitais. Pesquisado extensivamente em educação, arte e colaboração. Alta affordance, mas difíceis de escalar.
Atividade prática

Escolha dois aplicativos ou sistemas que você usa com frequência (pode ser um app de celular, um site, um programa de desktop ou uma ferramenta de linha de comando).

  • Identifique qual(is) estilo(s) de interação cada sistema utiliza.
  • Liste dois pontos onde o estilo escolhido ajuda o usuário na tarefa.
  • Liste um ponto onde o estilo escolhido limita o usuário.
  • Proponha: se você trocasse o estilo de interação principal, o que mudaria na experiência? O sistema ficaria melhor ou pior para o público-alvo atual?
