Funções recursivas e provas de corretude

Disciplina: Matemática Discreta – Bacharelado em Ciência da Computação (IFC São Bento do Sul)

Esta página foi feita para acompanhar a aula e também para que você possa estudar sozinho(a) e implementar os algoritmos apresentados. A ideia é: ler o conceito, ver o exemplo matemático, e em seguida codar a versão recursiva.

1. O que é recursão?

Objetivos da seção: Entender a ideia de recursão, ver a ligação com indução e reconhecer casos base e chamadas recursivas.

Uma função é recursiva quando ela é definida em termos de si mesma, mas sempre “diminuindo” o problema. De forma geral:

  • Caso base: situações mais simples, em que a resposta é direta.
  • Passo recursivo: expressa o problema em função de uma versão menor dele mesmo.

Exemplo rápido – Fatorial

Definição matemática recursiva:

  • \(0! = 1\) (caso base);
  • \(n! = n \cdot (n-1)!\) para \(n \geq 1\) (passo recursivo).

Perceba como é igual ao “formato” de uma prova por indução: base + passo que reduz de \(n\) para \(n-1\).

2. Definições recursivas de funções

Uma definição recursiva típica tem duas partes:

  1. Base: define o valor da função para um ou mais casos iniciais.
  2. Passo recursivo: define \(f(n)\) em função de valores “menores” \(f(k)\).

Exemplo 1 – Fatorial (matemática → algoritmo)

2.1. Definição matemática

\[ f(0) = 1,\quad f(n) = n \cdot f(n-1)\ \text{para}\ n \geq 1. \]

2.2. Como a recursão “anda”

Para calcular \(4!\):

  • \(4! = 4 \cdot 3!\)
  • \(3! = 3 \cdot 2!\)
  • \(2! = 2 \cdot 1!\)
  • \(1! = 1 \cdot 0!\)
  • \(0! = 1\) (base, pára aqui)

2.3. Algoritmo recursivo em C/Java-like

int fat(int n) {
    if (n == 0) {       // caso base
        return 1;
    }
    return n * fat(n - 1);  // chamada recursiva, problema menor
}

Atividade: copie este código para seu ambiente (C, C++, Java, etc.), execute para alguns valores e observe a sequência de chamadas.

Exemplo 2 – Sequência definida recursivamente

Considere a função \(f:\mathbb{N} \to \mathbb{Z}\) definida por:

  • \(f(0) = 3\);
  • \(f(n+1) = 2f(n) + 1\) para \(n \geq 0\).

Calcule manualmente \(f(1), f(2), f(3)\):

  • \(f(1) = 2f(0) + 1 = 2\cdot 3 + 1 = 7\);
  • \(f(2) = 2f(1) + 1 = 2\cdot 7 + 1 = 15\);
  • \(f(3) = 2f(2) + 1 = 2\cdot 15 + 1 = 31\).

Algoritmo correspondente

int f(int n) {
    if (n == 0) {       // caso base
        return 3;
    }
    return 2 * f(n - 1) + 1;  // passo recursivo
}

Atividade: implemente e confira se f(1), f(2) e f(3) batem com os valores calculados à mão.

3. Indução aplicada a funções recursivas

Objetivos: Ver como usar indução para provar propriedades de funções definidas recursivamente e ligar isso à corretude do algoritmo.

Exemplo 3 – Fechamento da função \(f(n)\)

Da seção anterior, temos:

  • \(f(0) = 3\);
  • \(f(n+1) = 2f(n) + 1\).

Conjectura (observando os valores 3, 7, 15, 31…):

\[ f(n) = 2^{n+2} - 1. \]

3.1. Prova por indução

Base: para \(n = 0\): \(f(0) = 3\). Pela fórmula,

\[ 2^{0+2} - 1 = 2^2 - 1 = 4 - 1 = 3. \]

Base ok.

Hipótese de indução: suponha que, para algum \(k \geq 0\),

\[ f(k) = 2^{k+2} - 1. \]

Passo indutivo: queremos mostrar que

\[ f(k+1) = 2^{(k+1)+2} - 1 = 2^{k+3} - 1. \]

Usando a definição recursiva:

\[ f(k+1) = 2f(k) + 1. \]

Substituindo a hipótese de indução:

\[ f(k+1) = 2(2^{k+2} - 1) + 1 = 2^{k+3} - 2 + 1 = 2^{k+3} - 1. \]

Logo, a fórmula vale para \(k+1\). Pela indução, vale para todo \(n \ge 0\).

3.2. Ligando com o algoritmo

Se implementarmos a função recursiva f(n) como no Exemplo 2, acabamos de provar que, para todo \(n\), o valor retornado é exatamente \(2^{n+2} - 1\). Isso é uma prova de corretude baseada em indução.

4. Exemplo clássico: Fibonacci

A sequência de Fibonacci é definida por:

  • \(F(0) = 0\), \(F(1) = 1\) (casos base);
  • \(F(n) = F(n-1) + F(n-2)\) para \(n \geq 2\) (passo recursivo).

4.1. Algoritmo recursivo de Fibonacci

int fib(int n) {
    if (n == 0) {      // caso base 1
        return 0;
    }
    if (n == 1) {      // caso base 2
        return 1;
    }
    return fib(n - 1) + fib(n - 2);  // chamadas recursivas
}

Esse algoritmo é didático, mas não é eficiente para valores grandes de n. Ainda assim, ele é ótimo para enxergar a estrutura recursiva.

4.2. Esboço de prova de corretude por indução forte

Queremos provar que, para todo \(n \geq 0\), a função fib(n) retorna o \(n\)-ésimo número de Fibonacci.

  1. Base: Verificar que fib(0) = 0 e fib(1) = 1, iguais à definição.
  2. Hipótese de indução forte: Suponha que, para todo \(k\) com \(0 \le k \le n\), fib(k) retorna o valor correto.
  3. Passo indutivo: Para \(n+1\), o código usa apenas fib(n) e fib(n-1). Pela hipótese, esses dois valores estão corretos, então fib(n+1) retorna \(F(n) + F(n-1) = F(n+1)\).

Concluímos, por indução forte, que o algoritmo está correto para todo \(n\).

5. Exercícios guiados (para você implementar)

Nos exercícios abaixo, siga o padrão: (1) entenda a definição matemática, (2) escreva a função recursiva, (3) pense em como provar a corretude por indução.

Exercício 1 – Potência recursiva

Defina recursivamente a função \(p(n) = x^n\) para \(n \ge 0\) e \(x \in \mathbb{R}\). Em seguida, implemente a versão recursiva em código e prove, por indução em \(n\), que a função realmente calcula \(x^n\).

Definição sugerida:

  • \(p(0) = 1\);
  • \(p(n) = x \cdot p(n-1)\) para \(n \ge 1\).
double pot(double x, int n) {
    if (n == 0) {
        return 1.0;
    }
    return x * pot(x, n - 1);
}

A prova por indução em \(n\) segue exatamente a definição: base em \(n=0\) e passo indutivo usando \(p(n) = x \cdot p(n-1)\).

Exercício 2 – Soma recursiva dos elementos de um vetor

Dado um vetor a[0..n-1], defina recursivamente a soma dos elementos \(S(n) = a_0 + a_1 + \dots + a_{n-1}\) e implemente um algoritmo recursivo que devolva essa soma. 

int somaVetor(int a[], int n) {
    if (n == 0) {      // vetor vazio
        return 0;
    }
    return somaVetor(a, n - 1) + a[n - 1];
}

Defina \(P(n)\): “somaVetor(a, n) retorna a soma de a[0..n-1]”. Prove por indução em \(n\) que \(P(n)\) é verdadeira para todo \(n \ge 0\).
