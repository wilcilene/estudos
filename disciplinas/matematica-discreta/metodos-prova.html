Aula 1: Definições Básicas de Provas

Objetivos: Entender o que é uma prova matemática e sua importância em Ciência da Computação (correção de algoritmos).

O que é uma Prova?

Uma prova é um argumento lógico rigoroso que estabelece a veracidade de uma afirmação para todos os casos relevantes. Provas garantem que algoritmos funcionam corretamente.

Afirmação: Para todo inteiro \( n \geq 1 \), a soma dos primeiros \( n \) números ímpares é \( n^2 \).
Prova necessária: Mostrar que vale para qualquer \( n \).

Prova por Indução: soma dos primeiros números ímpares

Afirmação: Para todo inteiro \( n \geq 1 \), vale

\[ 1 + 3 + 5 + \dots + (2n - 1) = n^2. \]

1. Passo base

Para \( n = 1 \):

  • Lado esquerdo: soma dos primeiros 1 número ímpar é \( 1 \).
  • Lado direito: \( 1^2 = 1 \).

Logo, a igualdade vale para \( n = 1 \).

Para \( n = 2 \):

  • Lado esquerdo: soma dos primeiros 2 número ímpar é \( 4 \).
  • Lado direito: \( 2^2 = 4 \).

Logo, a igualdade vale para \( n = 2 \).

2. Hipótese de indução

Suponha que a afirmação seja verdadeira para algum inteiro \( k \geq 1 \). Isto é, assumimos que

\[ 1 + 3 + 5 + \dots + (2k - 1) = k^2. \]

Esta suposição é a hipótese de indução.

3. Passo indutivo

Queremos mostrar que, sob essa hipótese, a afirmação vale para \( k + 1 \), ou seja, que

\[ 1 + 3 + 5 + \dots + (2k - 1) + (2(k+1) - 1) = (k+1)^2. \]

Note que o próximo número ímpar após \( 2k - 1 \) é \( 2(k+1) - 1 = 2k + 1 \).

Começamos da soma até \( k+1 \) e usamos a hipótese de indução:

\[ \begin{aligned} 1 + 3 + 5 + \dots + (2k - 1) + (2k + 1) &= \underbrace{(1 + 3 + \dots + (2k - 1))}_{\text{hipótese de indução}} + (2k + 1) \\ &= k^2 + (2k + 1). \end{aligned} \]

Agora somamos:

\[ k^2 + 2k + 1 = (k + 1)^2. \]

Portanto,

\[ 1 + 3 + 5 + \dots + (2k - 1) + (2k + 1) = (k + 1)^2. \]

Isso mostra que, se a igualdade vale para \( n = k \), então ela também vale para \( n = k+1 \).

4. Conclusão

Já vimos que a afirmação vale para \( n = 1 \) (passo base) e mostramos que, se vale para \( n = k \), então vale para \( n = k + 1 \) (passo indutivo). Assim, pelo Princípio da Indução Matemática, concluímos que

\[ 1 + 3 + 5 + \dots + (2n - 1) = n^2 \]

para todo inteiro \( n \geq 1 \).

Atividade em sala: Discuta por que contraexemplos refutam universalizações.

Aula 2: Prova Direta

Objetivos: Aprender a estrutura da prova direta e aplicar em problemas simples.

Estrutura da Prova Direta

Assuma a hipótese \( P \) verdadeira e derive logicamente a conclusão \( Q \), usando axiomas e teoremas conhecidos.

Teorema: Se a soma de dois inteiros é par, então a diferença é par.
Prova Direta: Seja \( m + n = 2k \) (par). Então \( m = 2a \), \( n = 2b \) ou ambos ímpares. Em ambos, \( m - n = 2(a - b) \) ou \( 2(a - b - 1) + 2 \), par.
Exemplo em Algoritmo:
Função ehPar(soma): return soma % 2 == 0
Prova: Se soma par, loop de adição preserva paridade.

Atividade: Prove que soma de racionais é racional.

Aula 3: Prova por Contraposição e Aplicações em Algoritmos (45 min)

Objetivos: Dominar contraposição e ligar a análise de algoritmos.

Prova por Contraposição

Para provar \( P \implies Q \), prove \( \neg Q \implies \neg P \) (equivalente) [web:20]. Útil quando \( \neg Q \) é mais fácil.

Teorema: Se \( n^2 \) é par, então \( n \) é par.
Contrapositiva: Se \( n \) ímpar, então \( n^2 \) ímpar.
Prova: \( n = 2k+1 \implies n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1 \), ímpar.
Aplicação em CS: Prova de terminação de algoritmo: "Se não termina, então loop infinito" (contrapositiva de "loop termina sempre").

Atividade: Prove transitividade da divisibilidade usando contraposição.

1. Direta:

Prove: Soma de dois racionais é racional.
Seja \( r = a/b \), \( s = c/d \). Então \( r + s = (ad + bc)/(bd) \), racional.

2. Contraposição:

Prove: Produto de dois ímpares é ímpar.
Contrapositiva: Se produto par, pelo menos um par. Prova: Suponha ambos ímpares → produto ímpar.
