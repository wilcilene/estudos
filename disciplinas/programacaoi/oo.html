Introdução à Orientação a Objetos

Programação I – Engenharia de Computação

1. Antes de tudo: o que é programar?

Programar é escrever instruções para que o computador execute tarefas. Em Programação I, normalmente começamos com comandos simples, variáveis, decisões (if) e repetições (for, while).

À medida que os programas crescem, precisamos de uma forma melhor de organizar o código. É nesse ponto que surge a Orientação a Objetos (OO).

👉 Pense na OO como uma forma de organizar o programa usando conceitos semelhantes aos do mundo real.

2. O que é uma Classe?

Uma classe é como um modelo ou um molde. Ela define como algo será, mas ainda não é esse algo.

Exemplo: antes de existir um estudante específico, existe a ideia de Estudante.

Primeira classe em Java

public class Estudante {
}
  • public: indica que a classe pode ser usada por outros arquivos
  • class: palavra-chave que cria uma classe
  • Estudante: nome da classe (sempre começa com letra maiúscula)

3. Atributos: as características do objeto

Os atributos representam as características de algo. No caso de um estudante, podemos ter:

  • RA
  • Nome
  • Notas
public class Estudante {
    int ra;
    String nome;
    double nota1;
    double nota2;
    double nota3;
}
Cada linha declara uma variável que pertence à classe. Essas variáveis serão copiadas para cada estudante criado.

4. Objetos: criando estudantes de verdade

Um objeto é um elemento criado a partir de uma classe. Se a classe é o molde, o objeto é o item pronto. 

public class Principal {
    public static void main(String[] args) {

        Estudante e1 = new Estudante();
        e1.ra = 1;
        e1.nome = "Ana";
        e1.nota1 = 8.5;
        e1.nota2 = 9.0;
        e1.nota3 = 7.0;
    }
}
  • new Estudante() cria um novo objeto
  • e1 é a variável que guarda o objeto
  • e1.nota1 acessa um atributo do objeto

5. Métodos: comportamentos do objeto

Métodos representam ações que o objeto pode realizar. Vamos criar um método para calcular a média. 

public class Estudante {

    double nota1, nota2, nota3;

    double calcularMedia() {
        return (nota1 + nota2 + nota3) / 3;
    }
}
  • double: tipo de valor que o método retorna
  • calcularMedia: nome do método
  • return: devolve o resultado do cálculo

6. Usando métodos no programa principal

public class Principal {
    public static void main(String[] args) {

        Estudante e1 = new Estudante();
        e1.nota1 = 8.5;
        e1.nota2 = 9.0;
        e1.nota3 = 7.0;

        double media = e1.calcularMedia();
        System.out.println("Média: " + media);
    }
}
O método é chamado usando:
nomeDoObjeto.nomeDoMetodo()

7. Construtores: inicializando o objeto corretamente

O construtor é um método especial chamado automaticamente quando o objeto é criado. 

public class Estudante {

    int ra;
    String nome;
    double nota1, nota2, nota3;

    public Estudante(int ra, String nome, double n1, double n2, double n3) {
        this.ra = ra;
        this.nome = nome;
        nota1 = n1;
        nota2 = n2;
        nota3 = n3;
    }
}
this diferencia o atributo da classe do parâmetro recebido.

8. Encapsulamento (primeiro contato)

Para proteger os dados, os atributos normalmente são private e acessados por métodos. 

private double nota1;

public void setNota1(double nota) {
    nota1 = nota;
}

public double getNota1() {
    return nota1;
}
🔒 Isso evita acessos indevidos e melhora a organização do código.

9. Atividade Prática

  1. Crie a classe Estudante
  2. Crie atributos para RA, nome e três notas
  3. Implemente um método para calcular a média
  4. No main, crie três estudantes
  5. Exiba a média de cada um
