Configurando o ambiente: MySQL Server e MySQL Workbench

Antes de executar os scripts DDL da disciplina, você precisa de duas coisas instaladas na sua máquina: o MySQL Server (o banco de dados propriamente dito) e o MySQL Workbench (o cliente gráfico usado para escrever e executar SQL). Este guia mostra o passo a passo para Windows, macOS e Linux.

O que você vai conseguir fazer ao final

  • Ter o MySQL Server instalado e em execução na sua máquina.
  • Ter o MySQL Workbench instalado e aberto.
  • Criar uma conexão local no Workbench e testar essa conexão.
  • Executar SELECT 1; com sucesso, confirmando que o ambiente está pronto.

1. Entendendo as duas peças do ambiente

É comum confundir as duas instalações, porque no dia a dia você vai abrir só o Workbench. Mas são dois programas com funções bem diferentes:

MySQL Server × MySQL Workbench
Programa O que é Fica rodando o tempo todo?
MySQL Server O banco de dados de verdade: um processo (serviço) que guarda os dados em disco e responde a comandos SQL enviados por uma conexão de rede. Sim, roda em segundo plano como um serviço do sistema operacional, mesmo sem nenhuma janela aberta.
MySQL Workbench Um programa com interface gráfica que se conecta ao MySQL Server, permite escrever SQL no editor e visualizar tabelas, colunas e resultados. Não, só roda enquanto você o mantém aberto — é só uma "janela" para o servidor.

Para quem já programa

A relação entre os dois é a mesma que existe entre um servidor de API e o Postman/Insomnia: o servidor guarda o estado e responde a requisições; o cliente gráfico só existe para facilitar o envio dessas requisições e a leitura das respostas. Fechar o Workbench não desliga o banco, do mesmo jeito que fechar o Postman não desliga sua API.

2. Antes de começar

  • Conexão de internet estável (os instaladores têm entre 300 MB e 600 MB).
  • Cerca de 1,5 GB de espaço livre em disco.
  • Permissão de administrador no computador (a instalação do servidor exige privilégios elevados nos três sistemas).
  • Anote, em algum lugar seguro, a senha que você vai definir para o usuário root do MySQL — ela será pedida sempre que o Workbench conectar ao servidor.

Escolha a seção correspondente ao seu sistema operacional abaixo. Os três caminhos terminam no mesmo lugar: seção 6, testando a primeira conexão.

3. Windows

No Windows, o caminho mais simples é o MySQL Installer, um único instalador que já oferece o Server e o Workbench juntos.

  1. Acesse dev.mysql.com/downloads/installer no navegador.
  2. Baixe a versão mysql-installer-community (o arquivo "web" é menor, mas baixa os componentes durante a instalação; o arquivo "full" já vem com tudo, recomendado se a internet do laboratório for instável).
  3. Execute o instalador baixado (arquivo .msi).
  4. Na tela Choosing a Setup Type, selecione Developer Default. Essa opção já marca o MySQL Server, o MySQL Workbench e as bibliotecas de conexão necessárias.
  5. Clique em Execute na tela seguinte para baixar e instalar cada componente marcado.
  6. Na etapa Type and Networking, mantenha a porta padrão 3306 e a opção Config Type: Development Computer.
  7. Na etapa Authentication Method, mantenha a opção recomendada (Use Strong Password Encryption).
  8. Na etapa Accounts and Roles, defina uma senha para o usuário root e anote-a.
  9. Na etapa Windows Service, mantenha a opção de configurar o MySQL como serviço do Windows, iniciando automaticamente com o sistema.
  10. Clique em Execute na tela final de configuração e aguarde a confirmação de que cada item foi concluído com sucesso.
  11. Finalize o instalador. O MySQL Workbench já estará disponível no menu Iniciar.

Conceito: o MySQL como serviço do Windows

Ao marcar a opção de serviço, o Windows passa a iniciar o MySQL Server automaticamente toda vez que o computador liga, sem precisar abrir nenhum programa manualmente. Para verificar se ele está ativo, abra o app Serviços (pesquise "Serviços" no menu Iniciar) e procure por MySQL80 (ou nome parecido) na lista — o status deve estar como Em execução.

Se preferir instalar cada parte separadamente (por exemplo, se o computador já tiver um MySQL Server e você só precisa do Workbench), baixe o instalador do Workbench isoladamente em dev.mysql.com/downloads/workbench, escolhendo a versão para Windows.

4. macOS

No macOS existem dois caminhos igualmente válidos. Escolha o que fizer mais sentido para você.

Opção A — Homebrew (recomendado para quem já usa terminal)

Se você já tem o Homebrew instalado, este caminho é o mais rápido.

brew update
brew install mysql
brew services start mysql
mysql_secure_installation
Linha a linha: instalação via Homebrew
Trecho O que significa
brew update Atualiza a lista de pacotes que o Homebrew conhece, garantindo que você instale a versão mais recente disponível do MySQL.
brew install mysql Baixa e instala o MySQL Server (o pacote de linha de comando, sem interface gráfica).
brew services start mysql Inicia o MySQL Server como um serviço em segundo plano e o configura para iniciar automaticamente sempre que você ligar o computador — o equivalente ao serviço do Windows visto na seção anterior.
mysql_secure_installation Executa um assistente interativo no terminal que define a senha do usuário root, remove usuários anônimos e aplica configurações de segurança recomendadas para um primeiro uso.

Em seguida, instale o Workbench (ele não vem junto com o pacote mysql do Homebrew):

brew install --cask mysqlworkbench

--cask indica ao Homebrew que este é um aplicativo com interface gráfica (não uma ferramenta de linha de comando), instalado como um app normal na pasta Aplicativos.

Opção B — Instaladores oficiais (sem usar terminal)

  1. Acesse dev.mysql.com/downloads/mysql e baixe o pacote DMG Archive para macOS.
  2. Abra o arquivo .dmg baixado e execute o instalador .pkg dentro dele.
  3. Siga o assistente; na tela de configuração, defina e anote a senha do usuário root.
  4. Ao final, abra Preferências do Sistema → MySQL para conferir se o servidor está em execução e para iniciá-lo automaticamente no login.
  5. Acesse dev.mysql.com/downloads/workbench, baixe o instalador para macOS e arraste o aplicativo para a pasta Aplicativos.

Para quem já programa

Se seu Mac usa chip Apple Silicon (M1/M2/M3/M4), tanto o Homebrew quanto os instaladores oficiais já distribuem binários nativos — não é preciso se preocupar com Rosetta para o MySQL Server ou para o Workbench nas versões atuais.

5. Linux (Ubuntu/Debian e derivados)

Os comandos abaixo usam apt, o gerenciador de pacotes do Ubuntu e de distribuições baseadas em Debian. Se você usa Fedora, openSUSE ou Arch, o processo é equivalente, trocando apt por dnf, zypper ou pacman.

sudo apt update
sudo apt install mysql-server
sudo systemctl status mysql
sudo mysql_secure_installation
Linha a linha: instalação do MySQL Server no Linux
Trecho O que significa
sudo apt update Atualiza a lista local de pacotes disponíveis nos repositórios configurados, para que o passo seguinte encontre a versão mais recente do MySQL.
sudo apt install mysql-server Instala o pacote do MySQL Server e todas as suas dependências. Ao final da instalação, o serviço já é iniciado automaticamente.
sudo systemctl status mysql Consulta o systemd (o gerenciador de serviços do Linux) para confirmar se o serviço mysql está com status active (running).
sudo mysql_secure_installation Assistente interativo que define a senha do usuário root, remove usuários e bancos de teste padrão e reforça as configurações de segurança — igual ao comando equivalente no macOS.

Para instalar o Workbench, você tem duas opções:

  1. Via apt (mais simples, se disponível na sua distribuição): sudo apt install mysql-workbench-community.
  2. Via Snap (se o pacote acima não existir no seu repositório): sudo snap install mysql-workbench-community.

Se nenhum dos dois estiver disponível, baixe o pacote .deb diretamente em dev.mysql.com/downloads/workbench, escolhendo a opção para Ubuntu, e instale com:

sudo apt install ./mysql-workbench-community_*.deb

O prefixo ./ indica ao apt que o pacote está em um arquivo local (na pasta atual), e não em um repositório remoto.

6. Criando a primeira conexão no Workbench

Este passo é igual nos três sistemas operacionais, depois que o MySQL Server e o Workbench estiverem instalados.

  1. Abra o MySQL Workbench.
  2. Na tela inicial, clique no ícone + ao lado de "MySQL Connections".
  3. Em Connection Name, dê um nome como Local ou Laboratório.
  4. Mantenha Hostname como 127.0.0.1 e Port como 3306 (valores padrão de uma instalação local).
  5. Em Username, digite root.
  6. Clique em Test Connection, informe a senha definida durante a instalação e confirme.
  7. Uma mensagem de sucesso confirma que o Workbench conseguiu falar com o servidor. Clique em OK e depois em OK novamente para salvar a conexão.
  8. Dê duplo clique na conexão salva para abrir o SQL Editor.

Para confirmar que tudo está funcionando, execute:

SELECT 1;
SELECT VERSION();
Linha a linha: teste final do ambiente
Trecho O que significa
SELECT 1; Não consulta nenhuma tabela — apenas pede ao servidor para devolver o número 1. Se o resultado aparecer sem erro, significa que a conexão entre Workbench e MySQL Server está funcionando de ponta a ponta.
SELECT VERSION(); Retorna a versão do MySQL Server instalada, útil para conferir se está de acordo com a versão recomendada pela disciplina.

7. Problemas comuns na instalação

Como investigar problemas comuns
Situação Causa provável Como investigar
Workbench mostra "Can't connect to MySQL server". O serviço do MySQL Server não está em execução. Windows: verifique em Serviços. macOS: brew services list ou Preferências do Sistema. Linux: sudo systemctl status mysql.
Erro "Access denied for user 'root'". Senha digitada não confere com a definida na instalação. Refaça a etapa de definição de senha (mysql_secure_installation no macOS/Linux, ou o assistente do MySQL Installer no Windows).
Porta 3306 já está em uso. Outra instalação do MySQL (ou outro serviço) já está usando essa porta. Verifique se não há uma instalação anterior do MySQL ainda ativa antes de instalar uma nova.
Comando brew ou apt não encontrado. Gerenciador de pacotes não instalado ou terminal errado. No macOS, instale o Homebrew em brew.sh antes de repetir os comandos. No Linux, confirme que está usando um terminal Bash/Zsh de uma distribuição baseada em Debian.
