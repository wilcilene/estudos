A base: Semana Acadêmica 2026

Participantes (alunos dos cursos do campus ou externos) se inscrevem em eventos — palestras, minicursos e oficinas — que acontecem em salas e são conduzidos por palestrantes. Depois do evento, registra-se a presença e o participante pode avaliar com uma nota de 1 a 5.

Detalhes que vão aparecer nas consultas id_curso nulo = participante externo · nota_avaliacao nula = não avaliou · valor zero = evento gratuito · presente começa como FALSE. No MySQL, BOOLEAN é um TINYINT(1): o Workbench mostra 1 para verdadeiro e 0 para falso.

Script inicial copiar e executar

Copiem o script completo, colem em uma aba de consulta do Workbench e executem de uma vez (⚡). Ele cria o banco semana_academica, as seis tabelas e insere 5 cursos, 16 participantes, 6 palestrantes, 5 salas, 12 eventos e 46 inscrições.

-- =========================================================
-- SEMANA ACADÊMICA 2026 — script da base inicial (MySQL 8)
-- Pode ser executado quantas vezes quiserem: ele apaga e recria tudo.
-- No Workbench: colem tudo e executem com o raio (Ctrl+Shift+Enter).
-- =========================================================

CREATE DATABASE IF NOT EXISTS semana_academica;
USE semana_academica;

-- Desliga o "Safe Updates" do Workbench nesta conexão, para que
-- UPDATE e DELETE com WHERE em colunas que não são chave funcionem.
SET SQL_SAFE_UPDATES = 0;

-- Limpeza (tabelas filhas primeiro, inclusive as criadas nos exercícios)
DROP TABLE IF EXISTS certificado;
DROP TABLE IF EXISTS evento_patrocinador;
DROP TABLE IF EXISTS patrocinador;
DROP TABLE IF EXISTS inscricao;
DROP TABLE IF EXISTS evento;
DROP TABLE IF EXISTS participante;
DROP TABLE IF EXISTS palestrante;
DROP TABLE IF EXISTS sala;
DROP TABLE IF EXISTS curso;

-- ---------------------------------------------------------
-- Estrutura (DDL)
-- ---------------------------------------------------------
CREATE TABLE curso (
  id_curso   INT          PRIMARY KEY,
  nome       VARCHAR(80)  NOT NULL,
  sigla      VARCHAR(10)  NOT NULL UNIQUE
);

CREATE TABLE participante (
  id_participante  INT          PRIMARY KEY,
  nome             VARCHAR(80)  NOT NULL,
  email            VARCHAR(100) NOT NULL UNIQUE,
  id_curso         INT,                         -- NULL = participante externo
  cidade           VARCHAR(50)  NOT NULL,
  data_nascimento  DATE,
  FOREIGN KEY (id_curso) REFERENCES curso (id_curso)
);

CREATE TABLE palestrante (
  id_palestrante  INT          PRIMARY KEY,
  nome            VARCHAR(80)  NOT NULL,
  instituicao     VARCHAR(80)  NOT NULL,
  area            VARCHAR(60)
);

CREATE TABLE sala (
  id_sala     INT          PRIMARY KEY,
  nome        VARCHAR(60)  NOT NULL,
  bloco       CHAR(1)      NOT NULL,
  capacidade  INT          NOT NULL CHECK (capacidade > 0)
);

CREATE TABLE evento (
  id_evento       INT           PRIMARY KEY,
  titulo          VARCHAR(100)  NOT NULL,
  tipo            VARCHAR(20)   NOT NULL CHECK (tipo IN ('Palestra', 'Minicurso', 'Oficina')),
  data_evento     DATE          NOT NULL,
  hora_inicio     TIME          NOT NULL,
  carga_horaria   INT           NOT NULL,
  vagas           INT           NOT NULL,
  valor           DECIMAL(6,2)  NOT NULL DEFAULT 0,
  id_sala         INT           NOT NULL,
  id_palestrante  INT           NOT NULL,
  FOREIGN KEY (id_sala)        REFERENCES sala (id_sala),
  FOREIGN KEY (id_palestrante) REFERENCES palestrante (id_palestrante)
);

CREATE TABLE inscricao (
  id_participante  INT      NOT NULL,
  id_evento        INT      NOT NULL,
  data_inscricao   DATE     NOT NULL,
  presente         BOOLEAN  NOT NULL DEFAULT FALSE,  -- no MySQL vira TINYINT(1): 1 = TRUE, 0 = FALSE
  nota_avaliacao   INT      CHECK (nota_avaliacao BETWEEN 1 AND 5),  -- NULL = não avaliou
  PRIMARY KEY (id_participante, id_evento),
  FOREIGN KEY (id_participante) REFERENCES participante (id_participante),
  FOREIGN KEY (id_evento)       REFERENCES evento (id_evento)
);

Criem a tabela certificado com:

  • id_certificado inteiro, chave primária;
  • id_participante e id_evento, obrigatórios, formando uma chave estrangeira composta que referencia inscricao;
  • codigo_validacao texto de até 20 caracteres, obrigatório e único;

Dica
A FK composta é declarada de uma vez: FOREIGN KEY (col1, col2) REFERENCES tabela (col1, col2). Para o padrão de data, o MySQL 8 exige parênteses em volta da expressão: DEFAULT (CURRENT_DATE).

Subconsultas também servem para DML. Escrevam e executem:
