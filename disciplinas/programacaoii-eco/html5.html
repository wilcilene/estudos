HTML5 e Estrutura de Documentos

Compreendendo a base semântica da web moderna e a organização de projetos front-end.

Introdução ao HTML5

O HTML5 não é apenas a quinta versão da linguagem de marcação; é uma plataforma de desenvolvimento completa que trouxe semântica, multimídia e APIs poderosas para o navegador.

Dica: HTML5 é sobre significado (semântica) e não apenas sobre como as coisas se parecem (apresentação).

Estrutura Semântica

Tags semânticas descrevem seu significado tanto para o navegador quanto para o desenvolvedor e tecnologias assistivas (leitores de tela).

  • <header>: Cabeçalho do documento ou seção.
  • <nav>: Conjunto de links de navegação.
  • <main>: Conteúdo principal e exclusivo da página.
  • <section>: Seção genérica de conteúdo temático.
  • <article>: Conteúdo independente e reutilizável.
  • <aside>: Conteúdo tangencial (barras laterais).
  • <footer>: Rodapé do documento ou seção.

Exemplo de Estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu Site</title>
</head>
<body>
    <header>
        <h1>Título do Site</h1>
        <nav>...</nav>
    </header>
    <main>
        <article>
            <h2>Postagem</h2>
            <p>Conteúdo...</p>
        </article>
    </main>
    <footer>
        <p>© 2026</p>
    </footer>
</body>
</html>

Novidades em Formulários

O HTML5 introduziu novos tipos de input que facilitam a validação e melhoram a experiência no mobile.

  • email
  • number
  • date
  • range
  • color
  • url
Validação nativa: Use o atributo required para campos obrigatórios e o navegador impedirá o envio sem preenchimento.
