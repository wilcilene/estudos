HTML5 e Estrutura de Documentos

Compreendendo a base semântica da web moderna e a organização de projetos front-end.

1. Introdução ao HTML5

O HTML5 representou uma revolução no desenvolvimento web, deixando de ser apenas uma linguagem de marcação para se tornar uma plataforma robusta. Seus principais pilares são:

  • Semântica: Dar significado ao conteúdo para máquinas e humanos.
  • Conectividade: Novas formas de comunicação com o servidor.
  • Multimídia: Suporte nativo a áudio e vídeo sem plugins externos.
  • APIs de Dispositivo: Acesso a geolocalização, câmera, armazenamento local, etc.
HTML5 é sobre "o que o conteúdo é" e não "como ele deve aparecer".

2. Estrutura Semântica (Layout)

O uso de tags semânticas é vital para a acessibilidade (leitores de tela) e SEO (motores de busca). Abaixo, as tags que definem as grandes áreas de uma página:

Principais Tags de Bloco:

  • <header>: Define o cabeçalho de uma página ou de uma seção específica. Geralmente contém títulos, logos e navegação.
  • <nav>: Destinado a blocos que contenham links de navegação principal.
  • <main>: Delimita o conteúdo principal e exclusivo da página. Só deve haver um por documento.
  • <section>: Agrupa conteúdos relacionados tematicamente (ex: seção de depoimentos, seção de preços).
  • <article>: Representa uma composição independente (ex: um post de blog, um comentário, um card de produto).
  • <aside>: Conteúdo periférico ou barras laterais que não são essenciais para o entendimento do conteúdo principal.
  • <footer>: Rodapé da página ou de uma seção.

Exemplo Prático de Código:

Observe a organização hierárquica abaixo. Note como cada tag "abraça" uma funcionalidade específica:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Exemplo de Estrutura HTML5</title>
</head>
<body>
    <header>
        <h1>Portal de Notícias</h1>
        <nav>
            <ul>
                <li><a href="#">Tecnologia</a></li>
                <li><a href="#">Educação</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <h2>Avanços do HTML5 em 2026</h2>
            <p>O desenvolvimento web nunca foi tão acessível...</p>
        </article>

        <section>
            <h2>Notícias Relacionadas</h2>
            <p>Confira outros tópicos importantes abaixo.</p>
        </section>
    </main>

    <aside>
        <h3>Publicidade</h3>
        <p>Anuncie aqui seu curso!</p>
    </aside>

    <footer>
        <p>© 2026 - Desenvolvido em Aula</p>
    </footer>
</body>
</html>

3. Formulários e Validação

O HTML5 trouxe tipos de campos que já realizam validação automática sem necessidade de JavaScript complexo.

Tipos de Input Úteis:
  • email: Valida o formato de e-mail.
  • number: Permite apenas números.
  • date: Abre um calendário nativo.
  • color: Seletor de cores do sistema.
  • range: Slider para seleção de valores.
  • tel: Para números de telefone.
Poder da Validação Nativa: Use o atributo required para tornar o campo obrigatório e placeholder para dar uma dica de preenchimento ao usuário.

4. Atividades Práticas

Atividade 1: Landing Page de Portfólio

Crie uma página para apresentar seu perfil profissional. Ela deve conter obrigatoriamente:

  • Um header com seu nome e uma nav com links (fictícios) para "Sobre", "Projetos" e "Contato".
  • Um main contendo dois article (descrição de dois projetos seus).
  • Um aside lateral com uma lista de suas habilidades (tags ul e li).
  • Um footer com suas redes sociais e copyright.

Atividade 2: Formulário de Pré-Inscrição

Desenvolva um formulário de contato que capture os seguintes dados usando os tipos de input corretos do HTML5:

  • Nome Completo (tipo text, obrigatório).
  • E-mail (tipo email, obrigatório).
  • Data de Nascimento (tipo date).
  • Nível de Conhecimento (tipo range de 0 a 10).
  • Cor Favorita para o tema (tipo color).
Entrega: Publique seus arquivos no repositório de projetos da disciplina e envie o link para a professora.
