Revisão de Conceitos de Orientação a Objetos

Programação II – Engenharia de Computação

1. Introdução à Orientação a Objetos

A Orientação a Objetos (OO) é um paradigma de programação que organiza o software a partir de objetos, que representam entidades do mundo real. Cada objeto possui atributos (dados) e métodos (comportamentos).

Todo programa Java possui ao menos uma classe definida pelo programador. A palavra-chave class introduz a definição da classe.

2. Classes, Objetos e Atributos

Uma classe funciona como um molde para criar objetos. Os objetos são instâncias dessa classe.

Exemplo de Classe em Java

public class Estudante {
    private int ra;
    private String nome;
    private double nota1, nota2, nota3;

    public Estudante(int ra, String nome, double n1, double n2, double n3) {
        this.ra = ra;
        this.nome = nome;
        this.nota1 = n1;
        this.nota2 = n2;
        this.nota3 = n3;
    }
}
Os atributos normalmente são declarados como private, garantindo o encapsulamento dos dados.

3. Métodos, Construtores e Main

Métodos realizam tarefas. O método main é o ponto de partida de qualquer aplicação Java. 

public static void main(String[] args) {
    System.out.println("Programa iniciado!");
}

Construtores

O construtor possui o mesmo nome da classe e é responsável por inicializar o objeto. 

public Estudante(int ra, String nome) {
    this.ra = ra;
    this.nome = nome;
}

4. Encapsulamento, Getters e Setters

O encapsulamento protege os dados do objeto, permitindo acesso controlado por meio de métodos get e set. 

public double getNota1() {
    return nota1;
}

public void setNota1(double nota1) {
    this.nota1 = nota1;
}

5. Herança

A herança permite que uma classe reutilize atributos e métodos de outra classe, utilizando a palavra-chave extends. 

public class AlunoGraduacao extends Estudante {
    private String curso;
}

6. Polimorfismo

O polimorfismo permite que métodos com o mesmo nome tenham comportamentos diferentes, dependendo do objeto que os executa. 

@Override
public double calcularMedia() {
    return (nota1 + nota2 + nota3) / 3;
}

7. Abstração e Interfaces

A abstração foca apenas no que o objeto faz, ocultando detalhes internos. Interfaces definem contratos que as classes devem implementar. 

public interface Avaliavel {
    double calcularMedia();
}
public class Estudante implements Avaliavel {
    public double calcularMedia() {
        return (nota1 + nota2 + nota3) / 3;
    }
}

8. Exceções

Exceções tratam situações inesperadas durante a execução do programa. 

try {
    int x = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Erro: divisão por zero.");
}

9. Arquivos

A leitura e escrita em arquivos permite persistência de dados. 

import java.io.File;
import java.util.Scanner;

File arquivo = new File("dados.txt");
Scanner sc = new Scanner(arquivo);

while (sc.hasNextLine()) {
    System.out.println(sc.nextLine());
}
sc.close();

Crie a classe Estudante, instancie três objetos, calcule e exiba a média. Altere as notas de um estudante e verifique as médias novamente.
