Revisão de Conceitos de Orientação a Objetos

Classes, herança, polimorfismo, abstração, interfaces, exceções e arquivos

Objetivo da revisão

Esta página tem como objetivo revisar os principais conceitos da Programação Orientada a Objetos (POO), fundamentais para o desenvolvimento de sistemas estruturados, reutilizáveis e de fácil manutenção.

Classe, objeto e atributos

Uma classe é um modelo que define atributos (dados) e métodos (comportamentos). Um objeto é uma instância concreta dessa classe. 


public class Estudante {

    private int ra;
    private String nome;
    private double nota1;
    private double nota2;
    private double nota3;
}

Construtor e encapsulamento

O construtor inicializa o objeto. O encapsulamento protege os dados, controlando o acesso por meio de métodos. 


public Estudante(int ra, String nome,
                 double nota1, double nota2, double nota3) {

    this.ra = ra;
    this.nome = nome;
    this.nota1 = nota1;
    this.nota2 = nota2;
    this.nota3 = nota3;
}

public String getNome() {
    return nome;
}

Abstração

Abstração consiste em representar apenas as características essenciais de um objeto, ignorando detalhes irrelevantes. 


public abstract class Pessoa {

    protected String nome;

    public abstract void apresentar();
}

Herança

A herança permite que uma classe herde atributos e métodos de outra, promovendo reutilização de código. 


public class Aluno extends Pessoa {

    @Override
    public void apresentar() {
        System.out.println("Sou um aluno");
    }
}

Polimorfismo

O polimorfismo permite que objetos diferentes respondam de forma distinta ao mesmo método. 


Pessoa p = new Aluno();
p.apresentar();

Interfaces

Interfaces definem contratos que devem ser implementados pelas classes. 


public interface Autenticavel {
    boolean autenticar(String senha);
}

Exceções e arquivos

Exceções tratam situações inesperadas, como erros de leitura de arquivos. 


try {
    Scanner sc = new Scanner(new File("dados.txt"));
} catch (Exception e) {
    System.out.println("Erro ao acessar o arquivo.");
}
