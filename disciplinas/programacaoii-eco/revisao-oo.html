Revisão de Conceitos de Orientação a Objetos

Classes, herança, polimorfismo, abstração, interfaces, exceções e arquivos

Objetivo do tópico

Este tópico tem como objetivo revisar e consolidar os conceitos fundamentais da Programação Orientada a Objetos (POO), servindo como base para o desenvolvimento de sistemas orientados a objetos ao longo da disciplina.

Classes, objetos e atributos

Todo programa Java possui ao menos uma classe definida pelo programador. Uma classe descreve a estrutura e o comportamento de seus objetos. 


public class Estudante {
    private int ra;
    private String nome;
    private double nota1, nota2, nota3;

    public Estudante(int ra, String nome,
                     double n1, double n2, double n3) {
        this.ra = ra;
        this.nome = nome;
        this.nota1 = n1;
        this.nota2 = n2;
        this.nota3 = n3;
    }
}

Diagrama de Classes (UML)


+---------------------------+
|         Estudante         |
+---------------------------+
| - ra: int                 |
| - nome: String            |
| - nota1: double           |
| - nota2: double           |
| - nota3: double           |
+---------------------------+
| + Estudante(...)          |
| + calcularMedia():double  |
| + getNome():String        |
+---------------------------+

O símbolo - indica atributos privados e + indica métodos públicos.

Métodos, construtores e encapsulamento

Métodos realizam tarefas. O construtor é responsável por inicializar corretamente o objeto no momento da criação. 


public double calcularMedia() {
    return (nota1 + nota2 + nota3) / 3;
}

public String getNome() {
    return nome;
}

O encapsulamento protege os dados do objeto, permitindo acesso controlado via métodos públicos.

Classe principal e método main

O método main é o ponto de entrada do programa Java. 


public class Principal {

    public static void main(String[] args) {

        Estudante e1 = new Estudante(1, "Ana", 8.5, 9.0, 7.0);
        Estudante e2 = new Estudante(2, "Julio", 5.0, 6.5, 8.0);
        Estudante e3 = new Estudante(3, "Wilcilene", 10.0, 10.0, 9.8);

        System.out.printf(
            "O estudante %s possui média %.2f%n",
            e1.getNome(), e1.calcularMedia()
        );
    }
}

Entrada de dados, atribuição e parâmetros


import java.util.Scanner;

Scanner sc = new Scanner(System.in);

System.out.print("Digite a nova nota: ");
double novaNota = sc.nextDouble();

e2.setNota1(novaNota);

O operador = atribui valores. O operador == realiza comparação.

Chamada de métodos


// método da mesma classe
calcularMedia();

// método de outra classe
e1.calcularMedia();

Herança, abstração e polimorfismo

A herança permite reutilização de código, a abstração define comportamentos essenciais e o polimorfismo permite múltiplas implementações.

Interfaces, exceções e arquivos


try {
    Scanner sc = new Scanner(new File("dados.txt"));
} catch (Exception e) {
    System.out.println("Erro ao ler arquivo.");
}

Para lembrar!

  • Todo objeto é criado com new
  • Métodos não static exigem objeto instanciado
  • Atributos devem ser private
  • Variáveis locais existem apenas dentro do método
  • Construtores inicializam corretamente o objeto

Atividade prática – Classe Estudante

  1. Crie a classe Estudante com atributos privados
  2. Implemente um construtor
  3. Crie método para cálculo da média
  4. Instancie três objetos na classe principal
  5. Altere notas usando Scanner
