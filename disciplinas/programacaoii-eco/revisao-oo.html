Revisão de Conceitos de Orientação a Objetos

Classes, herança, polimorfismo, abstração, interfaces, exceções e arquivos

Classes, objetos e atributos

Uma classe define a estrutura de seus objetos.


public class Estudante {

    // atributos (dados)
    private int ra;
    private String nome;
    private double nota1;
    private double nota2;
    private double nota3;
}

Construtor

O construtor inicializa o objeto no momento da criação.


public Estudante(int ra, String nome,
                 double nota1, double nota2, double nota3) {

    this.ra = ra;
    this.nome = nome;
    this.nota1 = nota1;
    this.nota2 = nota2;
    this.nota3 = nota3;
}

Métodos

Métodos realizam ações e podem retornar valores.


public double calcularMedia() {
    return (nota1 + nota2 + nota3) / 3;
}

public String getNome() {
    return nome;
}

Classe principal e método main


public class Principal {

    public static void main(String[] args) {

        Estudante e1 =
            new Estudante(1, "Ana", 8.5, 9.0, 7.0);

        System.out.printf(
            "O estudante %s possui média %.2f%n",
            e1.getNome(),
            e1.calcularMedia()
        );
    }
}

Entrada de dados com Scanner


import java.util.Scanner;

Scanner sc = new Scanner(System.in);

System.out.print("Digite a nota: ");

Chamada de métodos


// chamada de método do objeto
double media = e1.calcularMedia();
