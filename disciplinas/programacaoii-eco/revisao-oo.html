Classes, herança, polimorfismo, abstração, interfaces, exceções e arquivos

Objetivo do tópico

Revisar e consolidar os conceitos fundamentais da Programação Orientada a Objetos (POO), que servirão de base para o desenvolvimento de aplicações ao longo da disciplina.

Classes, objetos e atributos

Uma classe define a estrutura e o comportamento de seus objetos. Os atributos representam os dados do objeto. 


public class Estudante {

    private int ra;
    private String nome;
    private double nota1;
    private double nota2;
    private double nota3;
}

Construtor

O construtor é responsável por inicializar o objeto no momento da sua criação. 


public Estudante(int ra, String nome,
                 double nota1, double nota2, double nota3) {

    this.ra = ra;
    this.nome = nome;
    this.nota1 = nota1;
    this.nota2 = nota2;
    this.nota3 = nota3;
}

Métodos


public double calcularMedia() {
    return (nota1 + nota2 + nota3) / 3;
}

public String getNome() {
    return nome;
}

Classe principal e método main


public class Principal {

    public static void main(String[] args) {

        Estudante e1 =
            new Estudante(1, "Ana", 8.5, 9.0, 7.0);

        Estudante e2 =
            new Estudante(2, "Julio", 5.0, 6.5, 8.0);

        System.out.printf(
            "O estudante %s possui média %.2f%n",
            e1.getNome(),
            e1.calcularMedia()
        );
    }
}

Exceções e arquivos


import java.io.File;
import java.util.Scanner;

try {
    Scanner sc = new Scanner(new File("dados.txt"));
} catch (Exception e) {
    System.out.println("Erro ao ler o arquivo.");
}

Para lembrar!

  • Todo objeto é criado com new
  • Métodos não static exigem objeto instanciado
  • Atributos normalmente são private
  • Métodos get e set controlam o acesso
  • Construtores inicializam corretamente o objeto
