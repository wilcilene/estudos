Programação II

Aprofundamento em Programação Orientada a Objetos, padrões de projeto, arquitetura de software e desenvolvimento de aplicações completas.

Sobre a disciplina

A disciplina de Programação II consolida os conceitos fundamentais de Orientação a Objetos e avança para práticas modernas de desenvolvimento de software, com foco em qualidade, organização e manutenção de código.

Ao longo do curso, serão explorados padrões de projeto, princípios SOLID, APIs, banco de dados, desenvolvimento web e testes.
