Programação II

Aprofundamento em Programação Orientada a Objetos, desenvolvimento web, padrões de projeto e arquitetura de software.

Sobre a disciplina

A disciplina de Programação II consolida os conceitos fundamentais de Orientação a Objetos e avança para práticas modernas de desenvolvimento de software, com foco em desenvolvimento web full-stack.

Ao longo do curso, serão explorados padrões de projeto, JavaScript moderno, Node.js, Express, APIs REST, bancos de dados e autenticação.
