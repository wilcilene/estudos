Programação II

Aprofundamento em Programação Orientada a Objetos, padrões de projeto, arquitetura de software e desenvolvimento de aplicações completas.

Sobre a disciplina

A disciplina de Programação II consolida os conceitos fundamentais de Orientação a Objetos e avança para práticas modernas de desenvolvimento de software, com foco em qualidade, organização e manutenção de código.

Ao longo do curso, serão explorados padrões de projeto, princípios SOLID, APIs, banco de dados, desenvolvimento web e testes.

Conteúdos da disciplina

Revisão de conceitos de Orientação a Objetos

Classes, herança, polimorfismo, abstração, interfaces, exceções e arquivos.

Ferramentas e ambientes de desenvolvimento

IDEs, debugging, refatoração automatizada e versionamento com Git.

Gerenciamento de dependências

Organização e integração de bibliotecas externas.

Padrões de projeto criacionais

Singleton, Factory e Builder.

Padrões de projeto estruturais

Adapter, Decorator e Facade.

Padrões de projeto comportamentais

Observer, Strategy e Template Method.

Princípios SOLID e projetos OO

Boas práticas de design orientado a objetos.

APIs Java e desenvolvimento de APIs

Streams, Optional, Date/Time e APIs REST.

Interface gráfica

Introdução ao desenvolvimento de interfaces.

Modelagem e documentação

Diagramas, prototipação e documentação do projeto.

Banco de dados

Conceitos, conectividade e integração com aplicações.

Desenvolvimento web

HTML, CSS, frameworks web, segurança e arquitetura.

Testes e qualidade de software

Testes, refatoração, integração e deploy.
