Programação II

Disciplina focada no aprofundamento da Programação Orientada a Objetos, boas práticas de desenvolvimento, arquitetura de software e construção de aplicações robustas, manuteníveis e escaláveis.

Sobre a disciplina

Em Programação II, o estudante consolida os conceitos fundamentais de Orientação a Objetos e avança para práticas modernas de desenvolvimento de software, incluindo padrões de projeto, princípios SOLID, desenvolvimento de APIs, integração com banco de dados e aplicações web.

A disciplina combina teoria e prática, incentivando o pensamento crítico, a organização do código, o trabalho com ferramentas profissionais e a construção de projetos reais.

Conteúdos e Tópicos de Estudo

Revisão de conceitos de Orientação a Objetos

Classes, herança, polimorfismo, abstração, interfaces, exceções e manipulação de arquivos.

Ambientes e ferramentas de desenvolvimento

IDEs (Eclipse, IntelliJ, VS Code), configuração, debugging, refatoração e versionamento com Git.

Gerenciamento de dependências

Organização de bibliotecas, dependências externas e boas práticas de manutenção.

Padrões de Projeto Criacionais

Singleton, Factory e Builder aplicados a problemas reais.

Padrões Estruturais

Adapter, Decorator e Facade para organização e extensibilidade do código.

Padrões Comportamentais

Observer, Strategy e Template Method.

Princípios SOLID e projetos OO

Aplicação prática de princípios de design orientado a objetos.

APIs Java e desenvolvimento de APIs

Streams, Optional, Date/Time e construção de APIs REST.

Interface gráfica

Introdução ao desenvolvimento de interfaces para aplicações desktop ou web.

Modelagem e documentação

Diagramas de classes, casos de uso, prototipação e documentação do projeto.

Banco de dados

Revisão de conceitos, conectividade e integração com aplicações.

Desenvolvimento web

HTML, CSS, frameworks web, arquitetura, autenticação, segurança e deploy.

Testes e qualidade de software

Testes, refatoração contínua, integração e boas práticas.
