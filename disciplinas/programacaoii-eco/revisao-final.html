Visão geral Entregas Back-end Front-end API externa Orientação a Objetos

Visão geral

Esta revisão foi planejada para consolidar os conteúdos da disciplina em uma atividade prática compacta.

A proposta integra orientação a objetos, HTML5, DOM, JavaScript no navegador, Node.js com Express, consumo de APIs e tratamento de erros em um único exercício.

Proposta: desenvolver uma mini aplicação de loja virtual com catálogo, carrinho simples, API própria e uso de uma API pública externa.

Entregas esperadas

Entregar uma mini aplicação web com os seguintes componentes:

  • Um pequeno servidor em Node.js com Express.
  • Uma página HTML com interface funcional.
  • Um arquivo JavaScript de front-end com uso de DOM e fetch.
  • Um carrinho em memória, sem necessidade de persistência (sem banco).
  • Integração com uma API externa pública.
  • Um README curto explicando a solução.
  • Um parágrafo no final do README indicando como se conectaria com o banco.
Importante: o foco da revisão é integrar conceitos da disciplina em uma atividade curta, e não desenvolver um sistema completo com autenticação, banco e testes avançados. Entenda o código e aprenda os conceitos.

Parte 1 — Back-end

Implemente um servidor e uma entidade Produto, armazenando os dados em memória por meio de um array.

  • Classe: Produto com id, nome, categoria, preco e estoque.
  • GET /api/produtos para listar os produtos.
  • POST /api/produtos para cadastrar um produto.
  • PUT /api/produtos/:id/estoque para atualizar o estoque.
Validações mínimas
  • Nome obrigatório.
  • Preço numérico.
  • Estoque inteiro maior ou igual a zero.
  • Respostas com códigos adequados, como 400, 404 e 500.

Parte 2 — Front-end

Crie uma interface HTML5 simples para listar produtos e manipular um carrinho, utilizando JavaScript no navegador.

Estrutura sugerida para a interface
  • Listar produtos com botão “Adicionar ao carrinho”.
  • Mostrar os itens do carrinho com quantidade e total.
  • Permitir busca por nome.
  • Permitir filtro por categoria.
  • Usar innerHTML, eventos e manipulação do DOM.
  • Consumir a rota /api/produtos com fetch.
Obs: o carrinho pode existir apenas durante a execução da página, sem necessidade de salvar.

Parte 3 — API externa

Integre uma API pública simples, como uma API de cotação de moeda ou de consulta de CEP.

A chamada à API deve ser protegida com try/catch, mostrando mensagem amigável ao usuário em caso de erro.

Parte 4 — Revisão de OO

Inclua um pequeno módulo de revisão orientada a objetos com classes, herança e polimorfismo. 

class Usuario {
  constructor(nome, email) {
    this.nome = nome;
    this.email = email;
  }

  descricao() {
    return `Usuário: ${this.nome}`;
  }
}

class Admin extends Usuario {
  descricao() {
    return `Administrador: ${this.nome}`;
  }
}
  • Criar a classe Usuario.
  • Criar a classe Admin com extends.
  • Implementar o método descricao() com comportamento diferente nas duas classes.
  • Demonstrar um exemplo simples de instanciação e uso.

Critérios mínimos

  • Servidor executa e responde corretamente às rotas solicitadas.
  • Front-end consome a API e renderiza os produtos.
  • O carrinho calcula o total corretamente.
  • Há uso visível de classes, herança e polimorfismo.
  • A API externa foi integrada com tratamento de falha.
  • O projeto apresenta organização mínima e clareza de código.
