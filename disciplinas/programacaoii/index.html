Programação II – ECO

Projeto Orientado a Objetos · Padrões de Projeto · APIs · GUI · Banco de Dados · Web

Visão geral · Objetivos · Conteúdos · Projeto · Ferramentas
> “Código é projeto tornado executável.” ### 🎯 Visão geral da disciplina Programação II aprofunda os conceitos de Orientação a Objetos trabalhados em Programação I, focando em projeto de software, uso de APIs, interface gráfica, acesso a banco de dados e desenvolvimento web. Ao final do semestre, você deverá ser capaz de planejar e implementar uma aplicação completa em camadas, aplicando boas práticas de projeto, padrões de projeto (Design Patterns) e técnicas básicas de testes e deploy. #### Pré-requisito - Programação I (conceitos básicos de programação, introdução à Orientação a Objetos e interface gráfica). #### Como vamos trabalhar - Aulas expositivas dialogadas com demonstrações em IDE. - Atividades práticas em laboratório, com exercícios guiados e desenvolvimento incremental de um projeto. - Uso de repositórios no GitHub para organização do código e acompanhamento da evolução do projeto.
---
### 🧭 Objetivos de aprendizagem Ao concluir a disciplina, você deverá ser capaz de: - Revisar e aplicar conceitos fundamentais de Orientação a Objetos em projetos maiores. - Utilizar uma IDE moderna para desenvolver, depurar e refatorar aplicações. - Empregar padrões de projeto clássicos (GoF) para melhorar a organização e a manutenção do código. - Integrar APIs e bibliotecas externas às suas aplicações. - Criar interfaces gráficas mais ricas e conectá‑las a um backend. - Conectar aplicações a bancos de dados relacionais, realizando operações CRUD com segurança. - Desenvolver uma aplicação web simples, seguindo boas práticas de arquitetura, segurança e deploy.
---
### 📚 Conteúdos do semestre
1. Fundamentos e revisão - Revisão de conceitos de Orientação a Objetos
2. Ferramentas de desenvolvimento - Introdução a IDEs (Eclipse, IntelliJ, VS Code); configuração e debugging - Refatoração automatizada; versionamento com Git integrado - Gerenciamento de dependências
3. Padrões de projeto (Design Patterns) - Introdução aos GoF (criacionais: Singleton, Factory, Builder) - Estruturais (Adapter, Decorator, Facade) - Comportamentais (Observer, Strategy, Template) - Aplicação prática em projetos OO; princípios SOLID
4. APIs e bibliotecas - Preparação estudo de caso - Apresentação estudo de caso - APIs Java standard (Streams, Optional, Date/Time) - Desenvolvimento de APIs - Integração com bibliotecas externas
5. Interface gráfica e modelagem - Interface gráfica introdução - Prototipação, diagrama de classes, diagrama de casos de uso - Definição, análise e documentação do projeto
6. Backend, dados e integração - Programação backend projeto - Programação interface projeto - Revisão Banco de dados - Conectividade com Banco de Dados - Programação e conexão do banco de dados do projeto - Revisão e ajustes do projeto
7. Desenvolvimento web e deploy - Desenvolvimento web - Arquitetura e boas práticas - Frameworks web, HTML, CSS, APIs REST - Autenticação e segurança - Testes e Deploy
---
### 🛠️ Projeto da disciplina Durante o semestre, a turma desenvolverá um projeto aplicado que integrará interface gráfica, regras de negócio, acesso a banco de dados e, na etapa final, recursos web. O projeto será evoluído em etapas, alinhado aos tópicos apresentados em aula, permitindo que você veja a relação direta entre teoria e prática.
