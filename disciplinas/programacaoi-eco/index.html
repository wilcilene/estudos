Programação I

Introdução à programação com Java

Aprender programação é um processo progressivo. Cada semana representa um novo passo.

O que é esta disciplina

Esta disciplina apresenta os fundamentos da programação utilizando a linguagem Java. O objetivo é desenvolver raciocínio lógico, compreender conceitos de programação orientada a objetos e aprender a estruturar soluções computacionais para problemas reais.

Objetivos de aprendizagem

  • Desenvolver pensamento algorítmico.
  • Aprender os fundamentos da programação em Java.
  • Compreender os princípios da orientação a objetos.
  • Aplicar os conceitos em um projeto de software.

Projeto da disciplina

Durante o semestre será desenvolvido um projeto em Java no qual os estudantes aplicarão os conceitos aprendidos nas aulas. O projeto envolve análise do problema, modelagem do sistema, implementação e apresentação final.

Como vamos aprender

  • Aulas expositivas com demonstrações de programação.
  • Exercícios progressivos para fixação dos conceitos.
  • Resolução colaborativa de problemas.
  • Desenvolvimento de um projeto aplicado.
