3. Estruturas básicas em Java

Neste tópico consolidamos entrada e saída de dados com Scanner, operadores aritméticos e lógicos e as estruturas de controle if, while e for.

Exemplo – Lendo dados e tomando decisão

import java.util.Scanner;

public class MaiorIdade {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        System.out.print("Digite sua idade: ");
        int idade = entrada.nextInt();

        if (idade >= 18) {
            System.out.println("Maior de idade.");
        } else {
            System.out.println("Menor de idade.");
        }

        entrada.close();
    }
}
Lembre que o índice do for geralmente começa em 0, e o while repete “enquanto” a condição for verdadeira.

4. Decisões e loops com objetos

Avançamos nos if, switch, while, do-while e for, agora combinando essas estruturas com objetos e arrays de objetos.

Exemplo – Menu simples com objeto

class Conta {
    String titular;
    double saldo;

    void depositar(double valor) {
        saldo += valor;
    }
}

public class BancoMenu {

    public static void main(String[] args) {
        java.util.Scanner entrada = new java.util.Scanner(System.in);

        Conta conta = new Conta();
        conta.titular = "Ana";
        conta.saldo = 0.0;

        int opcao;
        do {
            System.out.println("1 - Depositar");
            System.out.println("2 - Ver saldo");
            System.out.println("0 - Sair");
            System.out.print("Opção: ");
            opcao = entrada.nextInt();

            if (opcao == 1) {
                System.out.print("Valor: ");
                double v = entrada.nextDouble();
                conta.depositar(v);
            } else if (opcao == 2) {
                System.out.println("Saldo: " + conta.saldo);
            }

        } while (opcao != 0);

        entrada.close();
    }
}

6. Orientação a objetos em Java (Semanas 11–12)

Estudamos também os conceitos de classe, objeto, encapsulamento e construtor em Java. A ideia é criar moldes de objetos com dados e comportamentos bem definidos.

Exemplo – Classe com construtor e encapsulamento em Java

class Produto {
    private String nome;
    private double preco;

    // Construtor
    public Produto(String nome, double preco) {
        this.nome = nome;
        this.preco = preco;
    }

    // Método que aplica desconto, protegendo a regra de negócio
    public void aplicarDesconto(double percentual) {
        if (percentual > 0 && percentual <= 100) {
            double desconto = preco * (percentual / 100);
            preco -= desconto;
        }
    }

    public void exibir() {
        System.out.println("Produto: " + nome);
        System.out.println("Preço: R$ " + preco);
    }
}

public class LojaOO {

    public static void main(String[] args) {
        Produto produto1 = new Produto("Mouse", 100.00);

        produto1.exibir();
        System.out.println("----------------");
        produto1.aplicarDesconto(10);
        produto1.exibir();
    }
}

Exercício 1 – Média da turma (Java)

Crie um programa em Java que:

  • leia do teclado a quantidade de alunos de uma turma;
  • use um array de double para armazenar as notas;
  • calcule a média e mostre quantos alunos ficaram: abaixo de 6, entre 6 e 7.9, e 8 ou mais.
import java.util.Scanner;

public class MediaTurma {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        System.out.print("Quantidade de alunos: ");
        int n = entrada.nextInt();

        double[] notas = new double[n];

        for (int i = 0; i < n; i++) {
            System.out.print("Nota do aluno " + (i + 1) + ": ");
            notas[i] = entrada.nextDouble();
        }

        double soma = 0.0;
        int abaixo6 = 0, entre6e79 = 0, acima8 = 0;

        for (int i = 0; i < n; i++) {
            soma += notas[i];

            if (notas[i] < 6) {
                abaixo6++;
            } else if (notas[i] < 8) {
                entre6e79++;
            } else {
                acima8++;
            }
        }

        double media = soma / n;

        System.out.println("Média: " + media);
        System.out.println("Abaixo de 6: " + abaixo6);
        System.out.println("Entre 6 e 7.9: " + entre6e79);
        System.out.println("8 ou mais: " + acima8);

        entrada.close();
    }
}

Exercício 2 – Lanchonete com objetos (Java)

Crie uma classe ItemPedido com os atributos nome (String), quantidade (int) e precoUnitario (double). Depois, faça um programa que:

  • use um ArrayList<ItemPedido> para armazenar os itens de um pedido;
  • mostre um menu simples para o usuário escolher entre cadastrar novo item, listar itens e ver o total do pedido;
  • encerre quando a opção “0 – sair” for escolhida.
import java.util.ArrayList;
import java.util.Scanner;

class ItemPedido {
    String nome;
    int quantidade;
    double precoUnitario;

    double calcularTotal() {
        return quantidade * precoUnitario;
    }
}

public class LanchoneteRevisao {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        ArrayList<ItemPedido> itens = new ArrayList<>();

        int opcao;
        do {
            System.out.println("\n1 - Adicionar item");
            System.out.println("2 - Listar itens");
            System.out.println("3 - Ver total");
            System.out.println("0 - Sair");
            System.out.print("Escolha: ");
            opcao = entrada.nextInt();
            entrada.nextLine();

            if (opcao == 1) {
                ItemPedido item = new ItemPedido();

                System.out.print("Nome do item: ");
                item.nome = entrada.nextLine();

                System.out.print("Quantidade: ");
                item.quantidade = entrada.nextInt();

                System.out.print("Preço unitário: ");
                item.precoUnitario = entrada.nextDouble();
                entrada.nextLine();

                itens.add(item);
            } else if (opcao == 2) {
                System.out.println("\n=== Itens do pedido ===");
                for (int i = 0; i < itens.size(); i++) {
                    ItemPedido it = itens.get(i);
                    System.out.println((i + 1) + ". " + it.nome
                            + " - qtd: " + it.quantidade
                            + " - total: R$ " + it.calcularTotal());
                }
            } else if (opcao == 3) {
                double total = 0.0;
                for (ItemPedido it : itens) {
                    total += it.calcularTotal();
                }
                System.out.println("Total do pedido: R$ " + total);
            }

        } while (opcao != 0);

        entrada.close();
    }
}

Exercício 3 – Controle de estudos (Java)

Crie uma classe EstudoDia com os atributos dia (String) e minutos (int). Escreva um programa que:

  • use um array de 7 posições para armazenar o tempo de estudo em cada dia da semana;
  • ao final, mostre o total de minutos e o dia com maior tempo de estudo.
import java.util.Scanner;

class EstudoDia {
    String dia;
    int minutos;
}

public class ControleEstudos {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        EstudoDia[] semana = new EstudoDia[7];

        String[] nomesDias = {
            "Segunda", "Terça", "Quarta", "Quinta",
            "Sexta", "Sábado", "Domingo"
        };

        int total = 0;
        EstudoDia maisEstudado = null;

        for (int i = 0; i < semana.length; i++) {
            semana[i] = new EstudoDia();
            semana[i].dia = nomesDias[i];

            System.out.print("Minutos estudados na " + nomesDias[i] + ": ");
            semana[i].minutos = entrada.nextInt();

            total += semana[i].minutos;

            if (maisEstudado == null || semana[i].minutos > maisEstudado.minutos) {
                maisEstudado = semana[i];
            }
        }

        System.out.println("\nTotal de minutos na semana: " + total);
        System.out.println("Dia com mais estudo: " + maisEstudado.dia
                + " (" + maisEstudado.minutos + " minutos)");

        entrada.close();
    }
}

Exercício 4 – Ingressos de cinema (PHP)

Em PHP, crie a classe IngressoCinema com os atributos filme, horario e meiaEntrada (boolean). Depois, escreva um script que:

  • use um loop while para cadastrar ingressos até o usuário enviar um filme vazio;
  • calcule o valor pago em cada ingresso (R$ 30,00 inteiro, R$ 15,00 meia);
  • ao final, exiba quantos ingressos foram vendidos e o total arrecadado.
<?php

class IngressoCinema {
    public $filme;
    public $horario;
    public $meiaEntrada;
    public $valorPago;

    public function __construct($filme, $horario, $meiaEntrada) {
        $this->filme = $filme;
        $this->horario = $horario;
        $this->meiaEntrada = $meiaEntrada;
        $this->valorPago = $meiaEntrada ? 15.0 : 30.0;
    }
}

$ingressos = [];
$totalFaturado = 0.0;

while (true) {
    echo "Filme (Enter para sair): ";
    $filme = trim(fgets(STDIN));

    if ($filme === "") {
        break;
    }

    echo "Horário (ex: 19:30): ";
    $horario = trim(fgets(STDIN));

    echo "Meia-entrada? (S/N): ";
    $resposta = trim(fgets(STDIN));

    $meia = (strtoupper($resposta) === "S");

    $ingresso = new IngressoCinema($filme, $horario, $meia);
    $ingressos[] = $ingresso;
    $totalFaturado += $ingresso->valorPago;
}

echo "Total de ingressos: " . count($ingressos) . PHP_EOL;
echo "Faturamento: R$ " . number_format($totalFaturado, 2, ",", ".") . PHP_EOL;

?>

Exercício 5 – Revisão geral (Java + conceito OO)

Em Java, modele uma classe Livro com os atributos titulo, autor e paginas. Crie:

  • um construtor que recebe todos os atributos;
  • um método resumir() que imprime uma frase com os dados;
  • um programa com um ArrayList<Livro> que: lê livros do teclado, guarda todos e depois mostra apenas os livros com mais de 300 páginas.
import java.util.ArrayList;
import java.util.Scanner;

class Livro {
    String titulo;
    String autor;
    int paginas;

    Livro(String titulo, String autor, int paginas) {
        this.titulo = titulo;
        this.autor = autor;
        this.paginas = paginas;
    }

    void resumir() {
        System.out.println(titulo + " - " + autor
                + " (" + paginas + " páginas)");
    }
}

public class BibliotecaRevisao {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);
        ArrayList<Livro> livros = new ArrayList<>();

        while (true) {
            System.out.print("Título do livro (fim para encerrar): ");
            String titulo = entrada.nextLine();

            if (titulo.equalsIgnoreCase("fim")) {
                break;
            }

            System.out.print("Autor: ");
            String autor = entrada.nextLine();

            System.out.print("Número de páginas: ");
            int paginas = entrada.nextInt();
            entrada.nextLine();

            livros.add(new Livro(titulo, autor, paginas));
        }

        System.out.println("\nLivros com mais de 300 páginas:");
        for (Livro l : livros) {
            if (l.paginas > 300) {
                l.resumir();
            }
        }

        entrada.close();
    }
}
