Fase 1 · 14/05 a 30/05

Fundamentos Laravel, Banco & Interface

Banco + UI Inicial

Meta até o checkpoint de 30/05: turma inteira com banco inicial definido em migrations e interface principal navegável, refletindo o protótipo.

Conteúdos de estudo

  • Revisão de PHP e Laravel básico Namespaces, classes, rotas, controllers, views Blade, comandos básicos do Artisan.
  • Modelagem de banco Definir entidades, atributos e relacionamentos com base no protótipo e nas regras do projeto.
  • Estrutura de interface Criar layouts base, menus e páginas correspondentes às telas principais (mural, inscrição, resultados).

Resultados esperados

  • Migrations iniciais criadas Pelo menos as tabelas centrais do sistema com migrations definidas e testadas.
  • Interface navegável Fluxo de navegação entre as principais páginas alinhado ao protótipo do Figma.
  • Quadro Scrum atualizado Cards de banco e interface atualizados com o status real de cada grupo.
Fase 2 · 01/06 a 13/06

Refinamento de Banco & Início do Backend

Model & Regras

Meta até o checkpoint de 13/06: banco refinado (migrations/Models coerentes) e backend iniciando os fluxos principais.

Estudo guiado

  • Vídeos de Migrations e Model Revisar vídeos sugeridos, focando em criação/alteração de migrations e uso de Eloquent.
  • Eloquent ORM Implementar Models com $fillable, relacionamentos (hasMany, belongsTo) e consultas básicas.

Produção no projeto

  • Banco refinado Ajustar estrutura (novas colunas, índices, relacionamentos) conforme necessidade identificada nas primeiras implementações.
  • Backend iniciando fluxos Controllers conectando Models às views, começando pelos fluxos mais críticos (por exemplo, criação de inscrição).
Fase 3 · 08/06 a 19/06

Fluxos principais completos

Funcionalidades

Meta: fluxos principais do protótipo funcionando de ponta a ponta (usuário → edital → inscrição → resultado) até a semana da apresentação.

Funcionalidades prioritárias

  • Autenticação e cadastro Implementar login, cadastro e perfis básicos conforme regras do projeto.
  • Mural de editais Listagem de editais com status (aberto/encerrado) e filtros simples.
  • Fluxo de inscrição Formulário de inscrição integrado ao banco, com validações de regras de negócio.

Integração com o quadro Scrum

  • Cards por fluxo Cada fluxo do sistema (ex.: “Implementar mural de editais”) deve ter um card associado no quadro, com responsável definido.
  • Checkpoint em cada aula Atualizar status dos cards (Backlog → Doing → Done) em toda aula, conectando com o cronograma acima.

Checklist rápido por aluno

  • Consigo rodar o projeto localmente sem erros.
  • Sei onde ficam rotas, controllers, models e views.
  • Entendo o papel da camada Model no MVC.
  • Consigo criar e rodar uma migration simples.
  • Consigo usar um Model para salvar e buscar dados.

Comandos Laravel essenciais

  • php artisan serve – inicia o servidor.
  • php artisan migrate – executa migrations.
  • php artisan migrate:rollback – desfaz a última migration.
  • php artisan make:model Nome -m – cria Model e migration.
  • php artisan tinker – console interativo para testar Models.

Boas práticas e alertas

  • Sincronizar código com o repositório frequentemente para evitar conflitos grandes.
  • Manter migrations e Models coerentes, atualizando ambos sempre que a estrutura mudar.
  • Evitar editar tabelas diretamente no banco sem criar migrations correspondentes.
  • Registrar cada funcionalidade concluída no quadro Scrum e nas issues do GitHub.
