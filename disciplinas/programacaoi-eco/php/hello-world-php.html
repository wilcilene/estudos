1. Introdução ao PHP

PHP é uma linguagem de script executada no lado do servidor, muito usada para construir páginas web dinâmicas.

Usaremos o XAMPP com PHP 8.5: arquivos .php salvos em htdocs podem ser abertos pelo navegador com endereços começando em http://localhost/.

Resumo conceitual
  • O navegador pede uma página .php ao servidor (Apache).
  • O servidor executa o código PHP e gera o código HTML como resposta.
  • O navegador lê o HTML final e exibe a página, não o código PHP.

Aspas simples x aspas duplas em echo

Em PHP, echo funciona com aspas simples ('...') e aspas duplas ("..."), mas elas se comportam de forma diferente em relação a variáveis.

  • Aspas simples não interpretam variáveis: o texto é exibido literalmente.
    $nome = 'Wilcilene';
    echo 'Olá, $nome';
  • Aspas duplas interpretam variáveis dentro da string (interpolação).
    $nome = 'Wilcilene';
    echo "Olá, $nome";

Regra prática: use aspas simples para textos fixos e concatene variáveis com .;
use aspas duplas quando quiser escrever a frase já com as variáveis dentro da própria string. $nome = 'Wilcilene';
