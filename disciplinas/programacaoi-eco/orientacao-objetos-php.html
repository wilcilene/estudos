1. O que vamos aprender

Nesta etapa da disciplina, vamos estudar como organizar programas usando objetos. Em vez de pensar apenas em variáveis soltas, passamos a modelar entidades do mundo real, como estudante, produto, conta, filme, ingresso...

Ideia central: orientação a objetos é uma forma de organizar melhor o código, aproximando a programação de coisas que existem no mundo real.

2. Antes de tudo: o que é um objeto?

Um objeto é uma estrutura que guarda dados e também pode ter comportamentos. Por exemplo: um Estudante pode ter nome e matricula, e um Produto pode ter descricao e preco.

Para criar objetos, usamos uma classe, que funciona como um molde. A classe define quais dados e comportamentos os objetos daquele tipo terão.

Classe

É o molde. Define atributos e métodos.

class Estudante {
    // definição
}

Objeto

É uma instância concreta criada a partir da classe.

$a1 = new Estudante();

Atributos

São os dados do objeto, como nome, idade ou preco.

private $nome;

Métodos

São as ações que o objeto pode realizar.

public function exibir() { }

3. Classes em PHP

Em PHP, uma classe é declarada com a palavra-chave class. Dentro dela, colocamos os atributos e os métodos relacionados.

Exemplo 1

<?php

class Livro {
    public $titulo;
    public $autor;

    public function exibirInformacoes() {
        echo "Livro: " . $this->titulo . "<br>";
        echo "Autor: " . $this->autor . "<br>";
    }
}

$livro1 = new Livro();
$livro1->titulo = "Introdução ao PHP";
$livro1->autor = "Maria Kowal";

$livro1->exibirInformacoes();
?>

Explicando o código

  • class Livro cria o molde do objeto.
  • public $titulo e public $autor são atributos.
  • public function exibirInformacoes() é um método.
  • $this->titulo significa “o título deste objeto”.
  • new Livro() cria um objeto baseado na classe.

4. Encapsulamento

Encapsulamento é a ideia de proteger os dados do objeto. Em vez de deixar tudo livre para ser alterado de qualquer jeito, controlamos o acesso usando métodos.

Em PHP, isso aparece com modificadores como public e private. Para começar:

  • public: pode ser acessado de fora da classe.
  • private: só pode ser acessado dentro da própria classe.

Exemplo 2 — Encapsulando atributos

<?php

class ContaBancaria {
    private $titular;
    private $saldo;

    public function definirTitular($nome) {
        $this->titular = $nome;
    }

    public function depositar($valor) {
        if ($valor > 0) {
            $this->saldo += $valor;
        }
    }

    public function exibirResumo() {
        echo "Titular: " . $this->titular . "<br>";
        echo "Saldo: R$ " . $this->saldo . "<br>";
    }
}

$conta = new ContaBancaria();
$conta->definirTitular("Ana");
$conta->depositar(150);
$conta->exibirResumo();

?>

Explicando o código

  • Os atributos $titular e $saldo são private.
  • Isso significa que eles não devem ser alterados diretamente fora da classe.
  • O método definirTitular() controla a mudança do titular.
  • O método depositar() só aceita valores maiores que zero.
  • Assim, a classe protege melhor seus próprios dados.
Resumo simples: encapsular é evitar bagunça. Em vez de qualquer parte do programa mexer nos dados de qualquer forma, a própria classe controla isso.

5. Construtores

Um construtor é um método especial que roda automaticamente quando o objeto é criado. Em PHP, o construtor tem o nome __construct().

Ele é útil para garantir que o objeto já nasça com valores importantes preenchidos.

Exemplo 3 — Usando construtor

<?php

class Filme {
    private $titulo;
    private $categoria;

    public function __construct($titulo, $categoria) {
        $this->titulo = $titulo;
        $this->categoria = $categoria;
    }

    public function exibirFicha() {
        echo "Filme: " . $this->titulo . "<br>";
        echo "Categoria: " . $this->categoria . "<br>";
    }
}

$filme1 = new Filme("Aventura no Espaço", "Ficção Científica");
$filme1->exibirFicha();

?>

Explicando o código

  • __construct() é chamado automaticamente ao usar new Filme(...).
  • O objeto já é criado com título e categoria.
  • Isso evita esquecer de preencher informações importantes depois.
  • Construtores ajudam a deixar os objetos mais consistentes.

6. Exemplo extra

A seguir, veja um exemplo que junta classe, encapsulamento e construtor em um único programa.

Exemplo 4 — Produto de loja

<?php

class Produto {
    private $nome;
    private $preco;

    public function __construct($nome, $preco) {
        $this->nome = $nome;
        $this->preco = $preco;
    }

    public function aplicarDesconto($percentual) {
        if ($percentual > 0 && $percentual <= 100) {
            $desconto = $this->preco * ($percentual / 100);
            $this->preco -= $desconto;
        }
    }

    public function exibirProduto() {
        echo "Produto: " . $this->nome . "<br>";
        echo "Preço atual: R$ " . number_format($this->preco, 2, ",", ".") . "<br>";
    }
}

$produto1 = new Produto("Mouse Gamer", 120.00);

$produto1->exibirProduto();
echo "<hr>";
$produto1->aplicarDesconto(10);
$produto1->exibirProduto();

?>

Explicando o código

  • A classe Produto tem os atributos privados $nome e $preco.
  • O construtor recebe esses valores no momento da criação do objeto.
  • O método aplicarDesconto() faz uma regra simples de negócio.
  • O método exibirProduto() mostra os dados formatados.
  • number_format() ajuda a exibir o preço no formato monetário brasileiro.

8. Exercícios para praticar

Agora é a sua vez. Tente resolver os exercícios primeiro. Depois, use o botão para ver uma solução possível.

Exercício 1 — Estudante

Crie uma classe Estudante com os atributos nome e curso. Use um construtor para receber esses valores e crie um método exibirDados(). 

<?php

class Estudante {
    private $nome;
    private $curso;

    public function __construct($nome, $curso) {
        $this->nome = $nome;
        $this->curso = $curso;
    }

    public function exibirDados() {
        echo "Estudante: " . $this->nome . "<br>";
        echo "Curso: " . $this->curso . "<br>";
    }
}

$estudante1 = new Estudante("Carlos", "Engenharia de Computação");
$estudante1->exibirDados();

?>

Exercício 2 — Conta de energia

Crie uma classe ContaEnergia com os atributos titular e valor. Use encapsulamento e crie um método que aplique desconto de 5% se a conta for maior que 200. 

<?php

class ContaEnergia {
    private $titular;
    private $valor;

    public function __construct($titular, $valor) {
        $this->titular = $titular;
        $this->valor = $valor;
    }

    public function aplicarDesconto() {
        if ($this->valor > 200) {
            $this->valor = $this->valor * 0.95;
        }
    }

    public function exibirConta() {
        echo "Titular: " . $this->titular . "<br>";
        echo "Valor final: R$ " . number_format($this->valor, 2, ",", ".") . "<br>";
    }
}

$conta = new ContaEnergia("Juliana", 240.00);
$conta->aplicarDesconto();
$conta->exibirConta();

?>

Exercício 3 — Personagem de jogo

Crie uma classe Personagem com os atributos nome e vida. Use construtor e crie um método receberDano($valor) que diminui a vida. 

<?php

class Personagem {
    private $nome;
    private $vida;

    public function __construct($nome, $vida) {
        $this->nome = $nome;
        $this->vida = $vida;
    }

    public function receberDano($valor) {
        $this->vida -= $valor;

        if ($this->vida < 0) {
            $this->vida = 0;
        }
    }

    public function exibirStatus() {
        echo "Personagem: " . $this->nome . "<br>";
        echo "Vida: " . $this->vida . "<br>";
    }
}

$p1 = new Personagem("Mago Azul", 100);
$p1->receberDano(35);
$p1->exibirStatus();

?>
Importante: em programação, quase sempre existe mais de uma solução possível. O objetivo é entender os conceitos, não decorar uma única resposta.

9. Para lembrar

  • Classe é o molde; objeto é a instância.
  • Encapsulamento ajuda a proteger os dados.
  • Construtores facilitam a criação de objetos prontos para uso.
  • PHP continua permitindo programação orientada a objetos de forma bem clara e didática.
