2. Saída de dados: mostrando informações no console

Saída de dados é tudo o que o programa “fala” para o usuário. Em Java, usamos principalmente System.out.print, System.out.println e System.out.printf.

System.out.println

Imprime o texto e pula para a próxima linha.


public class ExemploSaida {

    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
        System.out.println("Segunda linha de mensagem.");
    }
}

System.out.print

Imprime o texto, mas não pula de linha.


public class ExemploSaida2 {

    public static void main(String[] args) {
        System.out.print("Olá, ");
        System.out.print("estudante!");
        // Saída: Olá, estudante!
    }
}

System.out.printf

Permite formatar a mensagem, muito usado para números.


public class ExemploPrintf {

    public static void main(String[] args) {
        String nome = "Ana";
        double nota = 8.75;

        System.out.printf("Aluno(a): %s - Nota: %.2f%n", nome, nota);
    }
}

3. Entrada de dados: lendo informações do teclado

Para ler o que o usuário digita, usaremos a classe Scanner do pacote java.util.

1 Importar e criar o Scanner 

import java.util.Scanner;

public class EntradaSimples {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = entrada.nextLine();

        System.out.print("Digite sua idade: ");
        int idade = entrada.nextInt();

        System.out.println("Olá, " + nome + "! Você tem " + idade + " anos.");

        entrada.close();
    }
}

Lendo inteiros e decimais


import java.util.Scanner;

public class EntradaNumeros {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        System.out.print("Digite um número inteiro: ");
        int inteiro = entrada.nextInt();

        System.out.print("Digite um número decimal: ");
        double decimal = entrada.nextDouble();

        System.out.println("Inteiro = " + inteiro);
        System.out.println("Decimal = " + decimal);

        entrada.close();
    }
}

Lendo nome e sobrenome

Exemplo para treinar nextLine() e concatenação.


import java.util.Scanner;

public class NomeCompleto {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        System.out.print("Digite seu primeiro nome: ");
        String primeiro = entrada.nextLine();

        System.out.print("Digite seu sobrenome: ");
        String sobrenome = entrada.nextLine();

        String nomeCompleto = primeiro + " " + sobrenome;

        System.out.println("Olá, " + nomeCompleto + "!");

        entrada.close();
    }
}

4. Operadores: fazendo contas e comparações

Operadores aritméticos

  • + soma
  • - subtração
  • * multiplicação
  • / divisão
  • % resto da divisão (módulo)

public class OperadoresAritmeticos {

    public static void main(String[] args) {
        int a = 10;
        int b = 3;

        System.out.println("Soma: " + (a + b));
        System.out.println("Diferença: " + (a - b));
        System.out.println("Produto: " + (a * b));
        System.out.println("Quociente inteiro: " + (a / b));
        System.out.println("Resto da divisão: " + (a % b));
    }
}

Operadores relacionais

  • ==, !=
  • >, <, >=, <=

public class OperadoresRelacionais {

    public static void main(String[] args) {
        int x = 5;
        int y = 8;

        System.out.println(x == y); // false
        System.out.println(x != y); // true
        System.out.println(x < y);  // true
    }
}

Atenção: para comparar Strings, use .equals(), não ==.

Operadores lógicos

  • && (E lógico)
  • || (OU lógico)
  • ! (NÃO lógico)

public class OperadoresLogicos {

    public static void main(String[] args) {
        boolean temCarteira = true;
        boolean maiorDeIdade = false;

        boolean podeDirigir = temCarteira && maiorDeIdade;
        System.out.println("Pode dirigir? " + podeDirigir);
    }
}

5. Estruturas de controle: tomando decisões

Estruturas de controle definem “caminhos” diferentes no programa, dependendo dos valores das variáveis.

if e else


public class ExemploIf {

    public static void main(String[] args) {
        int idade = 17;

        if (idade >= 18) {
            System.out.println("Você é maior de idade.");
        } else {
            System.out.println("Você é menor de idade.");
        }
    }
}

if encadeado


public class ExemploIfEncadeado {

    public static void main(String[] args) {
        double nota = 8.5;

        if (nota >= 9.0) {
            System.out.println("Conceito A");
        } else if (nota >= 7.0) {
            System.out.println("Conceito B");
        } else if (nota >= 5.0) {
            System.out.println("Conceito C");
        } else {
            System.out.println("Conceito D");
        }
    }
}

switch (múltiplos casos)


public class ExemploSwitch {

    public static void main(String[] args) {
        int dia = 3;

        switch (dia) {
            case 1:
                System.out.println("Segunda-feira");
                break;
            case 2:
                System.out.println("Terça-feira");
                break;
            case 3:
                System.out.println("Quarta-feira");
                break;
            default:
                System.out.println("Outro dia");
        }
    }
}

6. Estruturas de repetição (loops)

Loops permitem repetir um bloco de código várias vezes. Aqui estão os três principais: while, do-while e for.

while


public class ExemploWhile {

    public static void main(String[] args) {
        int contador = 1;

        while (contador <= 5) {
            System.out.println("Valor: " + contador);
            contador = contador + 1;
        }
    }
}

do-while


public class ExemploDoWhile {

    public static void main(String[] args) {
        int numero = 1;

        do {
            System.out.println("Número: " + numero);
            numero++;
        } while (numero <= 3);
    }
}

for


public class ExemploFor {

    public static void main(String[] args) {
        for (int i = 0; i < 5; i++) {
            System.out.println("i vale: " + i);
        }
    }
}

Resumo mental: use for quando souber exatamente quantas vezes repetir; while quando repetir “enquanto” uma condição for verdadeira.

7. Exercícios com objetos e controle de fluxo

Agora vamos juntar estruturas básicas com manipulação de objetos. Em todos os exercícios, crie classes simples, instancie objetos, atribua valores e use entrada/saída para interagir com o usuário.

Exercício 1 – Cofrinho Digital

Crie uma classe Cofrinho com os atributos nomeDono (String) e saldo (double).
No main:

  • peça ao usuário o nome do dono e o valor que ele quer guardar;
  • crie um objeto Cofrinho, atribua o nome e atualize o saldo com o valor digitado;
  • mostre uma mensagem: "O cofrinho de NOME agora tem SALDO reais.".

import java.util.Scanner;

class Cofrinho {
    String nomeDono;
    double saldo;
}

public class ProgramaCofrinho {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        Cofrinho cofre = new Cofrinho();

        System.out.print("Nome do dono do cofrinho: ");
        cofre.nomeDono = entrada.nextLine();

        System.out.print("Quanto deseja guardar agora? ");
        double valor = entrada.nextDouble();

        cofre.saldo = valor;

        System.out.println("O cofrinho de " + cofre.nomeDono
                + " agora tem R$ " + cofre.saldo + " reais.");

        entrada.close();
    }
}

Exercício 2 – Termômetro de Sala

Crie uma classe Sala com os atributos nome (String) e temperatura (double).
No main:

  • leia do teclado o nome da sala e a temperatura atual;
  • crie um objeto Sala com esses valores;
  • use um if/else para dizer se a sala está “Fria” (< 20), “Confortável” (entre 20 e 25) ou “Quente” (> 25).

import java.util.Scanner;

class Sala {
    String nome;
    double temperatura;
}

public class ProgramaSala {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        Sala sala = new Sala();

        System.out.print("Nome da sala: ");
        sala.nome = entrada.nextLine();

        System.out.print("Temperatura atual da sala: ");
        sala.temperatura = entrada.nextDouble();

        System.out.println("Sala: " + sala.nome
                + " | Temperatura: " + sala.temperatura + " ºC");

        if (sala.temperatura < 20) {
            System.out.println("Situação: Fria");
        } else if (sala.temperatura <= 25) {
            System.out.println("Situação: Confortável");
        } else {
            System.out.println("Situação: Quente");
        }

        entrada.close();
    }
}

Exercício 3 – Agenda de Estudo

Crie uma classe Estudo com os atributos disciplina (String) e minutos (int).
No main:

  • peça ao usuário o nome de uma disciplina e quantos minutos ele estudou hoje;
  • crie um objeto Estudo e preencha os atributos;
  • use um if para escrever:
    • “Bom começo!” se minutos < 30;
    • “Boa dedicação!” se entre 30 e 59;
    • “Modo focado ativado!” se minutos ≥ 60.

import java.util.Scanner;

class Estudo {
    String disciplina;
    int minutos;
}

public class ProgramaEstudo {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        Estudo estudo = new Estudo();

        System.out.print("Disciplina estudada: ");
        estudo.disciplina = entrada.nextLine();

        System.out.print("Quantos minutos você estudou hoje? ");
        estudo.minutos = entrada.nextInt();

        System.out.println("Você estudou " + estudo.minutos
                + " minutos de " + estudo.disciplina + ".");

        if (estudo.minutos < 30) {
            System.out.println("Bom começo!");
        } else if (estudo.minutos < 60) {
            System.out.println("Boa dedicação!");
        } else {
            System.out.println("Modo focado ativado!");
        }

        entrada.close();
    }
}

Exercício 4 – Loja de Camisetas

Crie uma classe Camiseta com os atributos tamanho (String), cor (String) e preco (double).
No main:

  • leia tamanho, cor e preço digitados pelo usuário;
  • crie um objeto Camiseta com esses dados;
  • se o preço for maior que 100, mostre “Camiseta premium”; caso contrário, “Camiseta padrão”.

import java.util.Scanner;

class Camiseta {
    String tamanho;
    String cor;
    double preco;
}

public class ProgramaCamiseta {

    public static void main(String[] args) {
        Scanner entrada = new Scanner(System.in);

        Camiseta camiseta = new Camiseta();

        System.out.print("Tamanho da camiseta: ");
        camiseta.tamanho = entrada.nextLine();

        System.out.print("Cor da camiseta: ");
        camiseta.cor = entrada.nextLine();

        System.out.print("Preço da camiseta: ");
        camiseta.preco = entrada.nextDouble();

        System.out.println("Camiseta " + camiseta.cor
                + " tamanho " + camiseta.tamanho
                + " custa R$ " + camiseta.preco);

        if (camiseta.preco > 100) {
            System.out.println("Categoria: Camiseta premium");
        } else {
            System.out.println("Categoria: Camiseta padrão");
        }

        entrada.close();
    }
}
