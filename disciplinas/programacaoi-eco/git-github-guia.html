1. Criar sua conta no GitHub

  1. Acesse https://github.com
  2. Clique em Sign up
  3. Informe seu e-mail e crie um nome de usuário
  4. Confirme seu e-mail clicando no link enviado pelo GitHub

2. Instalar e configurar o Git no computador

2.1 Instalar o Git (Windows)

  1. Acesse https://git-scm.com/downloads e baixe o instalador
  2. Execute o arquivo baixado e avance lendo e clicando em Next até o fim
  3. Abra o terminal (Git Bash, Terminal, ou Prompt de Comando)
  4. Verifique a instalação: 
    git --version

2.2 Configurar

git config --global user.name "Seu Nome Completo"
  git config --global user.email "seu-email@ifc.edu.br"

4. Fluxo basico do Git

EtapaComandoDescrição
1. Iniciar repositóriogit initCria um repositório Git em uma pasta
2. Adicionar arquivosgit add .Coloca arquivos na área de preparação
3. Confirmar alteraçõesgit commit -m "mensagem"Registra um ponto na história do projeto
4. Enviar para o GitHubgit push origin mainEnvia os commits para o repositório remoto

5. Subindo seu primeiro projeto

  1. Não é necessário executar pensando na entrega da disiplina. Mas te ajuda entender melhor o fluxo.
  2. No GitHub, clique em New para criar um repositório (escolha público ou privado).
  3. No seu computador: 
    cd caminho/para/seu-projeto
git init
git add .
git commit -m "Primeiro commit"
  4. Conecte ao repositório remoto: 
    git remote add origin URL-DO-REPOSITORIO
git branch -M main
git push -u origin main

6. Entrega dos exercícios da disciplina

Para a disciplina de Programação I, temos um repositório no GitHub onde as entregas são organizadas por aula e por estudante (ou grupo).

wilcilene/prog1-eco-2026-entregas

Fluxo de entrega

  1. Clone o repositório: 
    git clone https://github.com/wilcilene/prog1-eco-2026-entregas.git
cd prog1-eco-2026-entregas
  2. Para cada aula, crie uma pasta com seu nome dentro da pasta da aula:
    exercicios/aula-01/seu-nome/
  3. Copie seus arquivos para essa pasta
  4. Envie para o GitHub: 
    git add .
      git commit -m "Entrega exercicios aula-01 - Seu Nome"
      git push

7. Projeto semestral em equipe

O projeto semestral será feito em equipes. Cada sprint faremos uma parte do sistema, mas o resultado final será uma única entrega.

Dentro do repositório da disciplina, cada equipe trabalhará na sua pasta e todos poderão contribuir:

projetos/equipes/equipe-01/
projetos/equipes/equipe-02/

Ao final, teremos o código integrado

Obs: Sempre digite mensagens de commit que expliquem resumidamente o que foi feito.
