1. Como usar esta página

Esta página reúne uma revisão rápida dos conceitos da disciplina e uma lista de exercícios em nível intermediário, parecidos com situações que podem aparecer na prova.

A ideia é que você releia cada tópico, revise os exemplos e depois tente resolver os exercícios sem olhar a resposta. Se tiver dificuldade peça ajuda ou clique no mostrar/ocultar para conferir. Mas tente resolver antes de olhar, pois olhar a resposta primeiro condiciona sua solução. Seja criativo e exercite seu pensamento lógico.

Dica para estudar: tente sempre escrever o código em um editor (VS Code, por exemplo), executar, testar com valores diferentes.

2. Como executar os exemplos em PHP (passo a passo)

Se você nunca usou PHP antes, siga estes passos para conseguir executar os exemplos da página. Vamos usar o PHP pela linha de comando, que é mais simples para começar.

2.1. Instalar o PHP

  1. Acesse o site oficial do PHP: https://www.php.net/downloads.php .
  2. Baixe a versão estável do PHP adequada ao seu sistema operacional (Windows, Linux ou macOS).
  3. Siga as instruções de instalação do seu sistema. Em muitos Linux e macOS o PHP já vem instalado ou pode ser instalado pelo gerenciador de pacotes (por exemplo, sudo apt install php).
  4. Depois de instalar, abra o terminal (Prompt de Comando, PowerShell ou Terminal) e digite: 
    php -v
    Se aparecer a versão do PHP, a instalação deu certo.

2.2. Criar um arquivo PHP

  1. Crie uma pasta para os testes, por exemplo C:\php-prova ou /home/seuusuario/php-prova.
  2. Abra essa pasta no VS Code (ou outro editor) e crie um arquivo chamado exemplo1.php.
  3. Copie e cole dentro dele um dos exemplos desta página. Lembre-se de manter as tags <?php no início e ?> no final quando estiverem presentes.
  4. Salve o arquivo.

2.3. Executar o arquivo pelo terminal

  1. Abra o terminal na mesma pasta onde salvou o arquivo (no VS Code você pode usar o menu Terminal → New Terminal).
  2. Digite o comando: 
    php exemplo1.php
  3. Se o script pedir entradas (por exemplo, “Digite sua idade:”), digite o valor no terminal e pressione Enter. O resultado aparecerá logo abaixo.

2.4. Dicas importantes

  • Cada exemplo da página pode ser salvo em um arquivo diferente: ex1.php, ex2.php, etc.
  • Comece testando exemplos bem pequenos (como “Olá, mundo”) antes de partir para exercícios longos.
  • Se aparecer uma mensagem de erro, leia com calma: geralmente o PHP informa a linha onde algo está escrito errado.
  • Se nada aparecer quando você executa, verifique se salvou o arquivo e se está na pasta correta no terminal.

2.5. Primeiro contato com Laravel

Depois de aprender a executar arquivos PHP simples, o próximo passo é conhecer o Laravel, que é um framework PHP usado para criar sistemas web mais organizados.

Pense assim: no PHP puro, você escreve scripts diretamente. No Laravel, você passa a trabalhar com uma estrutura pronta de projeto, com pastas, rotas, views e comandos que ajudam a desenvolver aplicações web maiores.

Importante: neste momento, o objetivo não é dominar Laravel, mas entender como criar e executar um projeto básico.

2.6. O que precisa estar instalado antes

  • PHP instalado no computador.
  • Composer instalado, porque o Laravel usa o Composer para gerenciar dependências.
  • De preferência, Node.js e NPM instalados, pois o Laravel recomenda isso para assets front-end.

Se o comando abaixo funcionar no terminal, o PHP está instalado: 

php -v

Se este funcionar, o Composer também está instalado: 

composer -V

2.7. Criando um projeto Laravel

Existem duas formas simples de criar o projeto. Para iniciantes, a mais fácil costuma ser usando o Composer.

Opção 1 – Criar projeto com Composer

composer create-project laravel/laravel meu-primeiro-laravel

Opção 2 – Usar o instalador do Laravel

laravel new meu-primeiro-laravel

Depois que o projeto for criado, entre na pasta: 

cd meu-primeiro-laravel

2.8. Executando o projeto

Para iniciar o servidor local do Laravel, use: 

php artisan serve

Em seguida, abra o navegador no endereço: 

http://localhost:8000

Se tudo estiver certo, você verá a página inicial padrão do Laravel.

2.9. Entendendo a ideia geral

No Laravel, você normalmente não começa escrevendo tudo em um único arquivo. Em vez disso, o framework organiza a aplicação em partes.

Rotas

Definem qual código será executado quando o usuário acessar uma URL.

routes/web.php

Views

São os arquivos que exibem HTML para o usuário.

resources/views/

Artisan

É a ferramenta de linha de comando do Laravel.

php artisan

2.10. Seu primeiro exemplo no Laravel

Um bom primeiro teste é criar uma rota simples que mostre uma mensagem na tela.

  1. Abra o projeto Laravel no VS Code.
  2. Abra o arquivo routes/web.php.
  3. Adicione este código:
<?php
    
    use Illuminate\Support\Facades\Route;
    
    Route::get('/', function () {
        return 'Olá! Este é meu primeiro teste com Laravel.';
    });

Agora salve o arquivo, volte ao navegador e recarregue a página em http://localhost:8000.

Se tudo deu certo, a mensagem será exibida na tela.

2.11. Próximo passo: mostrar uma página HTML

Depois de mostrar um texto simples, o próximo passo é fazer o Laravel retornar uma view.

  1. Crie o arquivo resources/views/inicio.blade.php.
  2. Dentro dele, escreva:
<h1>Olá!</h1>
    <p>Minha primeira página com Laravel.</p>
  1. Agora altere a rota em routes/web.php para:
<?php
    
    use Illuminate\Support\Facades\Route;
    
    Route::get('/', function () {
        return view('inicio');
    });

Ao recarregar o navegador, o Laravel passará a mostrar a página HTML criada por você.

Resumo: no começo, pense no Laravel assim: rota = endereço, view = página, artisan = comando do projeto.

4. Estruturas básicas em PHP

Neste tópico consolidamos entrada e saída de dados, operadores aritméticos e lógicos e as estruturas de controle if, while e for em PHP.

Exemplo – Lendo dados do terminal e tomando decisão

<?php

echo "Digite sua idade: ";
$linha = trim(fgets(STDIN));
$idade = (int) $linha;

if ($idade >= 18) {
    echo "Maior de idade." . PHP_EOL;
} else {
    echo "Menor de idade." . PHP_EOL;
}

?>
Lembre que o while repete “enquanto” a condição for verdadeira e o for é útil quando sabemos quantas repetições serão feitas.

5. Decisões, loops e arrays associativos

Aqui combinamos if, switch, while e for com arrays (simples e associativos) para representar pequenas estruturas de dados.

Exemplo – Menu simples com array associativo

<?php

$conta = [
    "titular" => "Ana",
    "saldo" => 0.0
];

do {
    echo "1 - Depositar" . PHP_EOL;
    echo "2 - Ver saldo" . PHP_EOL;
    echo "0 - Sair" . PHP_EOL;
    echo "Opção: ";
    $opcao = (int) trim(fgets(STDIN));

    if ($opcao === 1) {
        echo "Valor: ";
        $valor = (float) trim(fgets(STDIN));
        $conta["saldo"] += $valor;
    } elseif ($opcao === 2) {
        echo "Saldo: R$ " . $conta["saldo"] . PHP_EOL;
    }
} while ($opcao !== 0);

?>

6. Arrays em PHP

Depois, vimos como usar arrays numéricos e associativos em PHP para armazenar vários valores (ou estruturas) em uma única variável.

Array de inteiros

<?php

$numeros = [10, 20, 30];

for ($i = 0; $i < count($numeros); $i++) {
    echo $numeros[$i] . PHP_EOL;
}

?>

Array de arrays (estrutura de dados)

<?php

$tarefas = [];

$tarefas[] = ["descricao" => "Estudar para a prova"];

7. Orientação a objetos em PHP

Estudamos também os conceitos de classe, objeto, encapsulamento e construtor em PHP. A ideia é criar moldes de objetos com dados e comportamentos bem definidos.

Exemplo – Classe com construtor e encapsulamento em PHP

<?php

class Produto {
    private string $nome;
    private float $preco;

    public function __construct(string $nome, float $preco) {
        $this->nome = $nome;
        $this->preco = $preco;
    }

    public function aplicarDesconto(float $percentual): void {
        if ($percentual > 0 && $percentual <= 100) {
            $desconto = $this->preco * ($percentual / 100);
            $this->preco -= $desconto;
        }
    }

    public function exibir(): void {
        echo "Produto: " . $this->nome . PHP_EOL;
        echo "Preço: R$ " . number_format($this->preco, 2, ",", ".") . PHP_EOL;
    }
}

$produto1 = new Produto("Mouse", 100.00);

$produto1->exibir();
echo "----------------" . PHP_EOL;
$produto1->aplicarDesconto(10);
$produto1->exibir();

?>

Exercício 1 – Média da turma

Crie um script em PHP que:

  • leia do terminal a quantidade de alunos de uma turma;
  • use um array para armazenar as notas (números reais);
  • calcule a média e mostre quantos alunos ficaram: abaixo de 6, entre 6 e 7.9, e 8 ou mais.
<?php

echo "Quantidade de alunos: ";
$n = (int) trim(fgets(STDIN));

$notas = [];

for ($i = 0; $i < $n; $i++) {
    echo "Nota do aluno " . ($i + 1) . ": ";
    $notas[$i] = (float) trim(fgets(STDIN));
}

$soma = 0.0;
$abaixo6 = 0;
$entre6e79 = 0;
$acima8 = 0;

foreach ($notas as $nota) {
    $soma += $nota;

    if ($nota < 6) {
        $abaixo6++;
    } elseif ($nota < 8) {
        $entre6e79++;
    } else {
        $acima8++;
    }
}

$media = $soma / $n;

echo "Média: $media" . PHP_EOL;
echo "Abaixo de 6: $abaixo6" . PHP_EOL;
echo "Entre 6 e 7.9: $entre6e79" . PHP_EOL;
echo "8 ou mais: $acima8" . PHP_EOL;

?>

Exercício 2 – Lanchonete com objetos

Crie uma classe ItemPedido com os atributos nome (string), quantidade (int) e precoUnitario (float). Depois, escreva um script que:

  • use um array de ItemPedido para armazenar os itens de um pedido;
  • mostre um menu simples para o usuário escolher entre cadastrar novo item, listar itens e ver o total do pedido;
  • encerre quando a opção “0 – sair” for escolhida.
<?php

class ItemPedido {
    public string $nome;
    public int $quantidade;
    public float $precoUnitario;

    public function calcularTotal(): float {
        return $this->quantidade * $this->precoUnitario;
    }
}

$itens = [];

do {
    echo PHP_EOL;
    echo "1 - Adicionar item" . PHP_EOL;
    echo "2 - Listar itens" . PHP_EOL;
    echo "3 - Ver total" . PHP_EOL;
    echo "0 - Sair" . PHP_EOL;
    echo "Escolha: ";
    $opcao = (int) trim(fgets(STDIN));

    if ($opcao === 1) {
        $item = new ItemPedido();

        echo "Nome do item: ";
        $item->nome = trim(fgets(STDIN));

        echo "Quantidade: ";
        $item->quantidade = (int) trim(fgets(STDIN));

        echo "Preço unitário: ";
        $item->precoUnitario = (float) trim(fgets(STDIN));

        $itens[] = $item;
    } elseif ($opcao === 2) {
        echo PHP_EOL . "=== Itens do pedido ===" . PHP_EOL;
        foreach ($itens as $indice => $it) {
            echo ($indice + 1) . ". {$it->nome} - qtd: {$it->quantidade}"
                . " - total: R$ " . $it->calcularTotal() . PHP_EOL;
        }
    } elseif ($opcao === 3) {
        $total = 0.0;
        foreach ($itens as $it) {
            $total += $it->calcularTotal();
        }
        echo "Total do pedido: R$ " . $total . PHP_EOL;
    }

} while ($opcao !== 0);

?>

Exercício 3 – Controle de estudos

Crie uma classe EstudoDia com os atributos dia (string) e minutos (int). Escreva um script que:

  • use um array de 7 objetos EstudoDia para armazenar o tempo de estudo em cada dia da semana;
  • ao final, mostre o total de minutos e o dia com maior tempo de estudo.
<?php

class EstudoDia {
    public string $dia;
    public int $minutos;
}

$nomesDias = [
    "Segunda", "Terça", "Quarta", "Quinta",
    "Sexta", "Sábado", "Domingo"
];

$semana = [];
$total = 0;
$maisEstudado = null;

for ($i = 0; $i < 7; $i++) {
    $e = new EstudoDia();
    $e->dia = $nomesDias[$i];

    echo "Minutos estudados na {$e->dia}: ";
    $e->minutos = (int) trim(fgets(STDIN));

    $semana[] = $e;
    $total += $e->minutos;

    if ($maisEstudado === null || $e->minutos > $maisEstudado->minutos) {
        $maisEstudado = $e;
    }
}

echo PHP_EOL . "Total de minutos na semana: $total" . PHP_EOL;
echo "Dia com mais estudo: {$maisEstudado->dia}"
    . " ({$maisEstudado->minutos} minutos)" . PHP_EOL;

?>

Exercício 4 – Ingressos de cinema

Refaça o exercício de ingressos de cinema usando:

  • classe IngressoCinema com construtor e atributo valorPago calculado no construtor;
  • array de objetos para armazenar todos os ingressos;
  • ao final, mostr e uma listagem completa de ingressos e o faturamento total.
<?php

class IngressoCinema {
    public string $filme;
    public string $horario;
    public bool $meiaEntrada;
    public float $valorPago;

    public function __construct(string $filme, string $horario, bool $meiaEntrada) {
        $this->filme = $filme;
        $this->horario = $horario;
        $this->meiaEntrada = $meiaEntrada;
        $this->valorPago = $meiaEntrada ? 15.0 : 30.0;
    }
}

$ingressos = [];
$total = 0.0;

while (true) {
    echo "Filme (Enter para sair): ";
    $filme = trim(fgets(STDIN));

    if ($filme === "") {
        break;
    }

    echo "Horário (ex: 19:30): ";
    $horario = trim(fgets(STDIN));

    echo "Meia-entrada? (S/N): ";
    $resp = trim(fgets(STDIN));
    $meia = (strtoupper($resp) === "S");

    $ingresso = new IngressoCinema($filme, $horario, $meia);
    $ingressos[] = $ingresso;
    $total += $ingresso->valorPago;
}

echo PHP_EOL . "=== Ingressos vendidos ===" . PHP_EOL;
foreach ($ingressos as $i => $ing) {
    echo ($i + 1) . ". {$ing->filme} ({$ing->horario}) - R$ "
        . $ing->valorPago . PHP_EOL;
}

echo "Faturamento total: R$ "
    . number_format($total, 2, ",", ".") . PHP_EOL;

?>

Exercício 5 – Revisão geral OO

Modele uma classe Livro em PHP com os atributos titulo, autor e paginas. Crie:

  • um construtor que recebe todos os atributos;
  • um método resumir() que imprime uma frase com os dados;
  • um script que lê livros do terminal, guarda em um array de objetos e depois mostra apenas os livros com mais de 300 páginas.
<?php

class Livro {
    public string $titulo;
    public string $autor;
    public int $paginas;

    public function __construct(string $titulo, string $autor, int $paginas) {
        $this->titulo = $titulo;
        $this->autor = $autor;
        $this->paginas = $paginas;
    }

    public function resumir(): void {
        echo $this->titulo . " - " . $this->autor
            . " (" . $this->paginas . " páginas)" . PHP_EOL;
    }
}

$livros = [];

while (true) {
    echo "Título do livro (fim para encerrar): ";
    $titulo = trim(fgets(STDIN));

    if (strcasecmp($titulo, "fim") === 0) {
        break;
    }

    echo "Autor: ";
    $autor = trim(fgets(STDIN));

    echo "Número de páginas: ";
    $paginas = (int) trim(fgets(STDIN));

    $livros[] = new Livro($titulo, $autor, $paginas);
}

echo PHP_EOL . "Livros com mais de 300 páginas:" . PHP_EOL;
foreach ($livros as $livro) {
    if ($livro->paginas > 300) {
        $livro->resumir();
    }
}

?>
