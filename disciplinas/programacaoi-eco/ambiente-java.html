História da Computação, JDK e Primeiros Programas

Guia para você configurar o ambiente Java em casa e dar os primeiros passos

1. Uma viagem rápida pela história da computação

Esta aula será comentada rapidamente em sala, mas o estudo principal é feito por você, com calma. A ideia é ter contexto: de onde veio tudo isso até chegarmos ao Java.

Da contagem manual às máquinas

  • Ábaco e outras ferramentas de contagem.
  • Máquina Analítica de Charles Babbage (século XIX) como “ancestral” do computador programável.
  • Cartões perfurados usados em teares e depois em computadores.

Computadores eletrônicos

  • Primeiras máquinas eletrônicas na década de 1940 (ENIAC, Colossus).
  • Transistores e circuitos integrados permitindo computadores menores.
  • Chegada dos computadores pessoais (PCs) nas décadas de 70–80.

Do “código de máquina” ao Java

  • Linguagens de baixo nível (Assembly) evoluindo para linguagens de alto nível (C, Pascal, etc.).
  • Java surgindo na década de 90 com a proposta “Write Once, Run Anywhere”.
  • Hoje, Java roda em servidores, aplicações desktop, Android, sistemas embarcados e muito mais.

Dica: se quiser se aprofundar, procure depois por “gerações de computadores” e “história da linguagem Java”. Não é cobrado em prova, é cultura de programador.

2. O que exatamente você precisa instalar?

Para programar em Java em casa, vamos precisar de três elementos:

  • JDK (Java Development Kit): kit com compilador (javac) e ferramentas para desenvolver em Java.
  • Editor ou IDE: programa onde vamos escrever o código (usaremos VS Code, mas você pode usar outro se preferir).
  • Extensão de suporte ao Java no editor: para ter highlight, execução fácil e ajuda da IDE.

Objetivo desta página: que você consiga, sozinho(a), instalar tudo e rodar um “Olá, Mundo!” em casa, independente do sistema operacional.

3. Instalando o JDK no Windows Windows 10/11

1 Baixar o JDK

Acesse o site oficial da Oracle ou uma distribuição OpenJDK (como Temurin). Procure pela versão LTS (por exemplo, Java 17 ou 21) para Windows x64.

2 Executar o instalador

Depois de baixar o arquivo .exe, dê dois cliques e siga o assistente (Next > Next > Finish). Guarde o caminho de instalação (por exemplo, C:\Program Files\Java\jdk-17).

3 Configurar a variável de ambiente (se necessário)

Muitos instaladores já configuram o PATH automaticamente. Para conferir:

  1. Abra o menu Iniciar e digite cmd para abrir o Prompt de Comando.
  2. Digite java -version e pressione Enter.
  3. Digite javac -version e pressione Enter.

Se os comandos mostrarem a versão (por exemplo, 17.0.x), está tudo certo. Se aparecer mensagem de erro, será necessário ajustar o PATH nas variáveis de ambiente do Windows.

Se deu erro em javac: anote a mensagem e traga na próxima aula, mas tente antes reinstalar o JDK e marcar a opção que adiciona o Java ao PATH, se o instalador tiver.

4. Instalando o JDK no Linux Ubuntu / derivados

1 Abrir o terminal

Use o atalho Ctrl + Alt + T ou procure por “Terminal” no menu do sistema.

2 Instalar o OpenJDK pelo gerenciador de pacotes

No terminal, digite:

sudo apt update
sudo apt install -y openjdk-17-jdk
3 Conferir se deu certo

No terminal, rode:

java -version
javac -version

Se as versões aparecerem (por exemplo, openjdk version "17..."), o JDK está pronto.

Outras distribuições Linux: em Fedora, Arch, etc., o comando muda um pouco, mas a ideia é sempre instalar o pacote openjdk-XX-jdk pelo gerenciador de pacotes nativo.

5. Instalando o JDK no macOS macOS

1 Baixar o JDK

Acesse o site da Oracle ou uma distribuição OpenJDK para macOS (Intel ou Apple Silicon, conforme seu computador). Baixe o instalador .dmg.

2 Instalar

Abra o arquivo .dmg, clique duas vezes no pacote de instalação e siga o assistente.

3 Conferir no Terminal

Abra o app Terminal (via Spotlight) e digite:

java -version
javac -version

Se aparecer a versão do Java, o ambiente está configurado.

6. Instalando o VS Code e extensão de Java

1 Baixar e instalar o VS Code

Acesse o site do Visual Studio Code e baixe a versão para o seu sistema (Windows, Linux ou macOS). Instale normalmente (próximo, próximo, concluir).

2 Instalar a extensão de Java
  1. Abra o VS Code.
  2. Clique no ícone de extensões (quadradinho) na barra lateral esquerda.
  3. Pesquise por “Extension Pack for Java”.
  4. Clique em Install.
3 Conferir se a extensão reconheceu o JDK

Depois da instalação, o VS Code costuma detectar o JDK automaticamente. Se surgir uma mensagem sobre “Java runtime”, escolha o JDK que você instalou.

Importante: primeiro instale o JDK, depois o VS Code + extensão. Isso evita vários erros.

7. Seu primeiro programa Java pelo terminal

Antes de usar a IDE, vamos garantir que o compilador funciona. Siga os passos abaixo:

1 Criar o arquivo

Crie uma pasta simples, por exemplo C:\java-testes (Windows) ou ~/java-testes (Linux/macOS).

Dentro dela, crie um arquivo chamado OlaMundo.java com este conteúdo:


public class OlaMundo {

    public static void main(String[] args) {
        System.out.println("Olá, Mundo Java!");
    }
}
2 Compilar

Abra o terminal/prompt dentro dessa pasta e execute:

javac OlaMundo.java

Se tudo deu certo, um arquivo OlaMundo.class será criado.

3 Executar

No mesmo terminal, rode:

java OlaMundo

Você deve ver no console: Olá, Mundo Java!

Se aparecer erro: confira se o nome da classe é exatamente OlaMundo e se o arquivo tem o nome OlaMundo.java (sem espaços a mais).

8. Primeiro programa Java no VS Code

Agora vamos repetir a ideia do “Olá, Mundo!” usando o VS Code, como você fará nas próximas aulas.

1 Abrir a pasta do projeto
  1. Abra o VS Code.
  2. Clique em File > Open Folder... e selecione a pasta onde deseja guardar seus códigos de Java (por exemplo, java-projetos).
2 Criar o arquivo Java
  1. No VS Code, clique em “New File” e crie um arquivo chamado OlaEstudante.java.
  2. Cole o código abaixo:

public class OlaEstudante {

    public static void main(String[] args) {
        System.out.println("Olá, estudante de Programação I!");
    }
}
3 Executar pelo VS Code

Se a extensão de Java estiver instalada, deve aparecer um link ou ícone de Run (▶) perto do método main ou no canto superior direito do editor.

  1. Clique em Run ou use o atalho sugerido pela extensão.
  2. Veja o resultado na janela de saída/terminal integrada ao VS Code.

Meta desta página: se você conseguir chegar no “Olá, Mundo Java!” (terminal) e no “Olá, estudante de Programação I!” (VS Code), o ambiente está pronto para as próximas aulas.
