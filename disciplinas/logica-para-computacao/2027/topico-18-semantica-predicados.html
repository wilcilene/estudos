Caso Nº 18 · Lógica de Predicados

Semântica da Lógica de Predicados

Uma fórmula com quantificadores só ganha valor-verdade quando dizemos quem são os jogadores, as cartas e quem tem o quê. Isso é uma interpretação.

Ao final deste caso, vocês saberão
  • definir estrutura (domínio + interpretação) e atribuição de variáveis;
  • avaliar fórmulas quantificadas pela definição recursiva de satisfação;
  • expandir quantificadores em domínios finitos e estimar o custo disso;
  • negar quantificadores e saber quando eles se distribuem sobre ∧ e ∨;
  • construir contramodelos e entender por que a validade em primeira ordem é indecidível.

Do valor-verdade à estrutura

Imaginem…

Uma peça de teatro. O roteiro diz: “o vilão entra e pega a espada”. O roteiro é a fórmula. Mas a frase só fica verdadeira ou falsa numa apresentação concreta: quem faz o vilão, quais objetos estão no palco, quem segura o quê. Esse elenco com cenário é a estrutura. Com outro elenco, a mesma fala pode virar falsa.

Na lógica proposicional, uma valoração (uma linha da tabela) bastava para dar valor a qualquer fórmula. Em primeira ordem, eu preciso de mais coisa: de quais objetos estou falando e o que cada símbolo significa. Isso se chama uma estrutura (ou modelo, ou interpretação) 𝓜 = (D, I):

  • o domínio D: um conjunto não vazio de objetos;
  • a interpretação I: cada constante aponta para um objeto de D; cada função de aridade n vira uma função Dⁿ → D; cada predicado de aridade n vira um conjunto de n-uplas de D (as n-uplas em que ele é verdadeiro).

Para fórmulas com variáveis livres, também precisamos de uma atribuição s, que diz qual objeto cada variável representa no momento.

A definição de satisfação

Imaginem…

A atribuição de variáveis funciona como um crachá provisório. Quando a fórmula diz ∀x, cada objeto do domínio usa o crachá “x” por um momento, e a fórmula é testada com ele. ∀ exige que todos passem no teste com o crachá; ∃ exige que pelo menos um passe.

A notação 𝓜, s ⊨ φ lê-se “φ é verdadeira em 𝓜 com a atribuição s”. A definição segue a estrutura da fórmula, como a função avaliar do Caso 11:

FórmulaÉ verdadeira quando...
P(t₁, ..., tₙ)a n-upla dos objetos denotados por t₁, ..., tₙ pertence a I(P)
¬φ, φ ∧ ψ, ...como nas tabelas-verdade de sempre
∀x φpara todo d ∈ D, 𝓜, s[x ↦ d] ⊨ φ
∃x φpara algum d ∈ D, 𝓜, s[x ↦ d] ⊨ φ

s[x ↦ d] é a atribuição s com x trocado por d. Para sentenças, a atribuição não faz diferença, e escrevemos só 𝓜 ⊨ φ.

Avaliando num estado de partida

Uma estrutura do Detetive 
D = { j1, j2, Mordomo, Jardineiro, Faca, Corda }
I(Jogadora)   = { j1, j2 }
I(Suspeito)   = { Mordomo, Jardineiro }
I(Arma)       = { Faca, Corda }
I(Tem)        = { (j1, Faca), (j2, Mordomo) }
I(NoEnvelope) = { Jardineiro, Corda }
SentençaValorPor quê
∃x (Suspeito(x) ∧ NoEnvelope(x))Vx = Jardineiro serve.
∀x (Suspeito(x) → NoEnvelope(x))Fx = Mordomo é contraexemplo.
∀j (Jogadora(j) → ∃c Tem(j, c))Vj1 tem a Faca; j2 tem o Mordomo.
∀c (Tem(j1, c) → Arma(c))Va única carta de j1 é uma arma.
∃c (Tem(j1, c) ∧ NoEnvelope(c))Fnenhuma carta é ao mesmo tempo da mão de j1 e do envelope.

Domínios finitos: expansão

Se D = {d₁, ..., dₙ} e cada objeto tem um nome, os quantificadores viram conectivos:

∀x P(x)  ≡  P(d₁) ∧ P(d₂) ∧ ... ∧ P(dₙ)
∃x P(x)  ≡  P(d₁) ∨ P(d₂) ∨ ... ∨ P(dₙ)

Avaliar ficou mecânico, mas notem o custo: com k quantificadores aninhados, são nᵏ combinações. Em código, cada quantificador é um laço: ∀ é um all(...) e ∃ é um any(...). 

D = ["j1", "j2", "Mordomo", "Jardineiro", "Faca", "Corda"]
tem = {("j1", "Faca"), ("j2", "Mordomo")}
jogadora = {"j1", "j2"}

# ∀j (Jogadora(j) → ∃c Tem(j, c))
print(all((j not in jogadora) or any((j, c) in tem for c in D) for j in D))   # True

Negação e distribuição de quantificadores

EquivalênciaLeitura
¬∀x φ ≡ ∃x ¬φ“nem todos têm álibi” = “alguém não tem álibi”
¬∃x φ ≡ ∀x ¬φ“ninguém viu o crime” = “todos não viram”
∀x (φ ∧ ψ) ≡ ∀x φ ∧ ∀x ψ∀ distribui sobre ∧
∃x (φ ∨ ψ) ≡ ∃x φ ∨ ∃x ψ∃ distribui sobre ∨

São as leis de De Morgan para quantificadores: na expansão finita, ∀ é um grande ∧ e ∃ um grande ∨, e as leis do Caso 07 fazem o resto.

Erro comum

Distribuir ∀ sobre ∨ (ou ∃ sobre ∧). “Toda carta é arma ou suspeito” não implica “toda carta é arma ou toda carta é suspeito”. E “existe uma arma e existe um suspeito” não implica “existe algo que é arma e suspeito”.

Validade, contramodelos e indecidibilidade

Imaginem…

Procurar uma agulha num palheiro infinito. Se a agulha existe, um dia vocês a encontram, por mais que demore. Se ela não existe, vocês nunca sabem a hora de parar: talvez esteja no próximo punhado de palha. Provar validade em primeira ordem é assim.

Os conceitos do Caso 06 voltam com estruturas no lugar de linhas: uma sentença é válida se é verdadeira em toda estrutura, satisfatível se é verdadeira em alguma, e Γ ⊨ C se toda estrutura que satisfaz Γ satisfaz C. Para mostrar que uma consequência não vale, vocês constroem um contramodelo: uma estrutura em que as premissas são verdadeiras e a conclusão é falsa.

Agora vem a grande diferença. Há infinitas estruturas possíveis, inclusive com domínios infinitos, então não existe “tabela-verdade” para percorrer. Church e Turing provaram em 1936 que não existe algoritmo que decida, para toda sentença de primeira ordem, se ela é válida. Por outro lado, Gödel mostrou em 1929 (teorema da completude) que toda sentença válida tem uma demonstração. Juntando os dois: se a sentença é válida, uma busca por provas acaba encontrando; se não é, a busca pode não terminar nunca. Isso se chama semidecidibilidade, e vai aparecer de novo no Caso 20.

No Detetive

O estado real de uma partida é uma estrutura: quem tem cada carta e o que está no envelope. Nenhuma jogadora conhece essa estrutura inteira. O que cada uma tem é um conjunto de pistas Γ, e o que ela pode afirmar com segurança é o que vale em todas as estruturas compatíveis com Γ, isto é, as consequências lógicas. Cada estrutura compatível em que o culpado é diferente é um contramodelo para a sua acusação. Acusar cedo demais é ignorar um contramodelo.

Exercício 1 · Avaliação

No domínio {Mordomo, Jardineiro}, com I(Culpado) = {Mordomo}, avalie ∀x Culpado(x) e ∃x ¬Culpado(x).

Ver resposta

∀x Culpado(x) é falsa (o Jardineiro não satisfaz). ∃x ¬Culpado(x) é verdadeira (o Jardineiro satisfaz). Coerente com ¬∀x Culpado(x) ≡ ∃x ¬Culpado(x).

Exercício 2 · Contramodelo

Mostrem que ∀x (A(x) ∨ S(x)) ⊭ ∀x A(x) ∨ ∀x S(x).

Ver resposta

D = {Faca, Mordomo}, I(A) = {Faca}, I(S) = {Mordomo}. A premissa é verdadeira (cada objeto é arma ou suspeito), mas ∀x A(x) é falsa (Mordomo) e ∀x S(x) também (Faca).

Exercício 3 · Expansão

Expandam ∀j ∃c Tem(j, c) considerando apenas as jogadoras {j1, j2} e as cartas {Faca, Corda}.

Ver resposta

(Tem(j1, Faca) ∨ Tem(j1, Corda)) ∧ (Tem(j2, Faca) ∨ Tem(j2, Corda)). Reparem: já é uma FNC, pronta para um resolvedor SAT.

Para guardar
  • Estrutura = domínio não vazio + significado de cada constante, função e predicado.
  • ∀x: vale para todo objeto; ∃x: vale para algum. A avaliação é recursiva.
  • Domínio finito: ∀ vira ∧, ∃ vira ∨, com custo nᵏ.
  • ¬∀ ≡ ∃¬ e ¬∃ ≡ ∀¬; ∀ distribui sobre ∧, ∃ sobre ∨, e não o contrário.
  • Validade em primeira ordem é indecidível, mas semidecidível.
