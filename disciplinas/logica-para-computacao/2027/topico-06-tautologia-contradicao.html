Caso Nº 06 · Semântica

Tautologia, Contradição e Contingência

Com a tabela pronta, olhamos para a coluna final e fazemos a pergunta decisiva: a fórmula é sempre verdadeira, sempre falsa ou depende do cenário?

Ao final deste caso, vocês saberão
  • classificar uma fórmula como tautologia, contradição ou contingência;
  • relacionar essas classes com satisfatibilidade e validade;
  • provar que uma fórmula é tautologia sem montar a tabela inteira;
  • usar a substituição uniforme para gerar tautologias novas a partir de antigas;
  • reconhecer tautologias famosas que viram regras de inferência.

Três destinos possíveis para uma fórmula

Imaginem…

Três moedas num cofrinho de brincadeira:

  • uma moeda com cara dos dois lados: jogue quantas vezes quiser, sempre dá cara;
  • uma moeda com coroa dos dois lados: nunca dá cara;
  • uma moeda normal: às vezes cara, às vezes coroa.

Trocando “cara” por “verdadeiro” e “jogar a moeda” por “escolher uma linha da tabela”, temos as três classes de fórmulas: tautologia, contradição e contingência.

Depois de montar a tabela-verdade, olhem para a coluna final. Só existem três possibilidades:

Palavras novas

Modelo de uma fórmula: uma linha (valoração) em que ela é verdadeira. Satisfatível: tem pelo menos um modelo, ou seja, pelo menos uma linha V. Tautologias e contingências são satisfatíveis; contradições não.

As relações que importam

Guardem estas três relações. Elas parecem simples, mas são a base dos algoritmos a partir do Caso 12:

  • A é tautologia se e somente se ¬A é contradição.
  • A é contradição se e somente se A não é satisfatível.
  • Logo, A é tautologia se e somente se ¬A não é satisfatível.
Imaginem…

Negar uma fórmula é virar a moeda do avesso: cara vira coroa em todas as faces. A moeda “sempre cara” vira a moeda “sempre coroa”. Então, para saber se uma moeda é “sempre cara”, basta perguntar se a moeda do avesso alguma vez dá cara. Se nunca dá, a original era sempre cara.

Essa última relação é preciosa: um programa que só sabe responder “esta fórmula tem algum modelo?” também consegue verificar tautologias. Basta perguntar sobre a negação. É exatamente isso que fazemos na resolução por refutação.

Por que tautologias importam

Uma tautologia é verdadeira em qualquer cenário. Por isso ela não traz informação sobre o caso (“o suspeito é culpado ou não é” não elimina nenhuma linha do bloco de anotações), mas traz informação sobre o raciocínio. Quando a fórmula (premissas) → conclusão é tautologia, o argumento é válido, como veremos no Caso 08. Uma contradição, por outro lado, revela anotações incompatíveis: alguma pista foi mal registrada ou alguém mentiu.

Uma forma útil de pensar: uma pista é tanto mais informativa quanto mais linhas ela elimina. Uma tautologia elimina zero linhas (não informa nada). Uma contradição elimina todas (informa “demais”: nenhum cenário sobra). As pistas úteis de uma investigação são contingências, que eliminam algumas linhas e deixam outras.

Provando tautologias sem a tabela inteira

Usem a avaliação reversa do Caso 05: suponham que a fórmula é F e procurem uma contradição. Se toda tentativa falhar, a fórmula é tautologia. Se der certo, vocês encontraram um contraexemplo, e ela não é.

Modus ponens como fórmula

Provemos que ((p → q) ∧ p) → q é tautologia.

Suponham F. Então ((p → q) ∧ p) = V e q = F.
Da conjunção verdadeira:  (p → q) = V  e  p = V.
Com p = V e q = F:  (p → q) = F.     Contradição!

Não há como falsificar a fórmula. Ela é tautologia, e é por isso que o modus ponens é uma regra segura (Caso 09).

Quando a tentativa encontra um contraexemplo

Será que (p → q) → (q → p) é tautologia?

Suponham F. Então (p → q) = V e (q → p) = F.
(q → p) = F obriga q = V e p = F.
Conferindo (p → q) com p = F, q = V:  F → V = V.   Nenhuma contradição!

A valoração p = F, q = V torna a fórmula falsa: ela não é tautologia. A tentativa de falsificar funcionou e nos entregou o contraexemplo de bandeja.

Substituição uniforme: uma fábrica de tautologias

Imaginem…

Uma forma de biscoito em formato de estrela. Não importa se a massa é de chocolate, de baunilha ou de cenoura: o biscoito sai em formato de estrela. A forma é a tautologia; a massa é o que vocês colocam no lugar das letras.

Toda instância de uma tautologia também é tautologia. Se vocês trocarem p por (B ∧ M) em p ∨ ¬p, obtêm (B ∧ M) ∨ ¬(B ∧ M), que continua sempre verdadeira. A única regra é trocar a mesma variável pela mesma fórmula em todos os lugares onde ela aparece (por isso o nome “uniforme”). O motivo: a coluna de (B ∧ M) só tem V e F, exatamente como a coluna de p, e a tautologia já funcionava para qualquer valor de p.

Erro comum

“Contingência” não quer dizer “fórmula fraca”. A maioria das pistas de um caso real são contingências, porque elas dizem algo sobre o mundo e poderiam ser falsas. O que não pode acontecer é o conjunto das pistas virar uma contradição.

Outro erro: substituir de forma não uniforme. Trocar só o primeiro p de p ∨ ¬p por q dá q ∨ ¬p, que não é tautologia.

No Detetive

Imaginem que vocês anotaram “o crime foi na Cozinha” (porque nenhum outro local sobrou) e, mais tarde, alguém mostrou a carta Cozinha. A conjunção das anotações virou C ∧ ¬C: uma contradição. Isso não quer dizer que o jogo esteja quebrado; quer dizer que alguma anotação anterior está errada. E cuidado com a explosão: de anotações contraditórias, a lógica “prova” qualquer acusação. Detectar contradições é tão importante quanto encontrar o culpado.

Exercício 1 · Classifiquem
  1. p → p
  2. p ↔ ¬p
  3. (p → q) ∨ (q → p)
  4. p ∧ (¬p ∨ q)
  5. ¬(p → q) ∧ q
Ver resposta

1. Tautologia. 2. Contradição: p e ¬p nunca têm o mesmo valor. 3. Tautologia, por mais estranho que pareça: se q é V, o primeiro termo é V; se q é F, o segundo termo é V. 4. Contingência: V só quando p = V e q = V. 5. Contradição: ¬(p → q) exige q = F, mas a conjunção exige q = V.

Exercício 2 · Provem por avaliação reversa

Mostrem que o silogismo disjuntivo ((p ∨ q) ∧ ¬p) → q é tautologia.

Ver resposta

Suponham F: o antecedente é V e q = F. Do antecedente, ¬p = V, logo p = F, e p ∨ q = V. Mas com p = F e q = F, p ∨ q = F. Contradição: a fórmula é tautologia.

Exercício 3 · Substituição uniforme

A partir do modus tollens ((p → q) ∧ ¬q) → ¬p, gerem a tautologia correspondente com p := (b ∧ m) e q := k, e leiam-na no contexto do Detetive.

Ver resposta

(((b ∧ m) → k) ∧ ¬k) → ¬(b ∧ m): “se crime na Biblioteca com o Mordomo implica Candelabro, e a arma não é o Candelabro, então não é verdade que foi na Biblioteca com o Mordomo”. É tautologia sem precisar de tabela.

Para guardar
  • Tautologia: sempre V. Contradição: sempre F. Contingência: depende (moeda normal).
  • Satisfatível = tem pelo menos um modelo (tautologias e contingências).
  • A é tautologia ⇔ ¬A é insatisfatível.
  • Para provar tautologia, tentem falsificá-la; se falharem, está provado; se conseguirem, ganharam um contraexemplo.
  • Substituição uniforme de uma tautologia gera outra tautologia.
