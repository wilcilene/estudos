Caso Nº 06 · Semântica

Tautologia, Contradição e Contingência

Com a tabela pronta, olhamos para a coluna final e fazemos a pergunta decisiva: a fórmula é sempre verdadeira, sempre falsa ou depende do cenário?

Ao final deste caso, vocês vão saber
  • classificar uma fórmula como tautologia, contradição ou contingência;
  • relacionar essas classes com satisfatibilidade e validade;
  • provar que uma fórmula é tautologia sem montar a tabela inteira;
  • reconhecer tautologias famosas que vão virar regras de inferência.

Três destinos possíveis para uma fórmula

Depois de montar a tabela-verdade, olhem para a coluna final. Só existem três possibilidades:

ClasseColuna finalExemploOutros nomes
Tautologiasó Vp ∨ ¬pfórmula válida
Contradiçãosó Fp ∧ ¬pfórmula insatisfatível
ContingênciaV e Fp → qsatisfatível, mas não válida

Existe ainda uma quarta palavra que vocês vão usar muito: uma fórmula é satisfatível quando tem pelo menos uma linha V. Ou seja, tautologias e contingências são satisfatíveis; contradições não.

As relações que importam

Guardem estas três relações. Elas parecem simples, mas são a base dos algoritmos que veremos a partir do Caso 12:

  • A é tautologia se e somente se ¬A é contradição.
  • A é contradição se e somente se A não é satisfatível.
  • Logo, A é tautologia se e somente se ¬A não é satisfatível.

Essa última é preciosa: um programa que só sabe responder “esta fórmula tem algum modelo?” também consegue verificar tautologias. Basta perguntar sobre a negação. É exatamente isso que fazemos na resolução por refutação.

Por que tautologias importam

Uma tautologia é verdadeira em qualquer cenário. Por isso ela não traz informação sobre o caso (“o suspeito é culpado ou não é” não ajuda a investigação), mas traz informação sobre o raciocínio. Quando a fórmula (premissas) → conclusão é tautologia, o argumento é válido, como veremos no Caso 08. Uma contradição, por outro lado, revela anotações incompatíveis: alguma pista foi mal registrada ou alguém mentiu.

Provando tautologias sem a tabela inteira

Usem a avaliação reversa do Caso 05: suponham que a fórmula é F e procurem uma contradição. Se toda tentativa falhar, a fórmula é tautologia. Se der certo, vocês encontraram um contraexemplo, e ela não é.

Modus ponens como fórmula

Vamos provar que ((p → q) ∧ p) → q é tautologia.

Suponha F. Então ((p → q) ∧ p) = V e q = F.
Da conjunção verdadeira:  (p → q) = V  e  p = V.
Com p = V e q = F:  (p → q) = F.     Contradição!

Não há como falsificar a fórmula. Ela é tautologia, e é por isso que o modus ponens é uma regra segura (Caso 09).

Tautologias que vocês vão reencontrar

NomeTautologia
Terceiro excluídop ∨ ¬p
Não contradição¬(p ∧ ¬p)
Modus ponens((p → q) ∧ p) → q
Modus tollens((p → q) ∧ ¬q) → ¬p
Silogismo hipotético((p → q) ∧ (q → r)) → (p → r)
Silogismo disjuntivo((p ∨ q) ∧ ¬p) → q
Contrapositiva(p → q) ↔ (¬q → ¬p)

Reparem num detalhe: toda instância de uma tautologia também é tautologia. Se vocês trocarem p por (B ∧ M) em p ∨ ¬p, obtêm (B ∧ M) ∨ ¬(B ∧ M), que continua sempre verdadeira.

Erro comum

“Contingência” não quer dizer “fórmula fraca”. A maioria das pistas de um caso real são contingências, porque elas dizem algo sobre o mundo e poderiam ser falsas. O que não pode acontecer é o conjunto das pistas virar uma contradição.

No Detetive

Imaginem que vocês anotaram “o crime foi na Cozinha” (porque nenhum outro local sobrou) e, mais tarde, alguém mostrou a carta Cozinha. A conjunção das anotações virou C ∧ ¬C: uma contradição. Isso não quer dizer que o jogo esteja quebrado; quer dizer que alguma anotação anterior está errada. Detectar contradições é tão importante quanto encontrar o culpado.

Exercício 1 · Classifique
  1. p → p
  2. p ↔ ¬p
  3. (p → q) ∨ (q → p)
  4. p ∧ (¬p ∨ q)
  5. ¬(p → q) ∧ q
Ver resposta

1. Tautologia. 2. Contradição: p e ¬p nunca têm o mesmo valor. 3. Tautologia, por mais estranho que pareça: se q é V, o primeiro termo é V; se q é F, o segundo termo é V. 4. Contingência: V só quando p = V e q = V. 5. Contradição: ¬(p → q) exige q = F, mas a conjunção exige q = V.

Exercício 2 · Prove por avaliação reversa

Mostrem que o silogismo disjuntivo ((p ∨ q) ∧ ¬p) → q é tautologia.

Ver resposta

Suponha F: o antecedente é V e q = F. Do antecedente, ¬p = V, logo p = F, e p ∨ q = V. Mas com p = F e q = F, p ∨ q = F. Contradição: a fórmula é tautologia.

Para guardar
  • Tautologia: sempre V. Contradição: sempre F. Contingência: depende.
  • Satisfatível = tem pelo menos um modelo (tautologias e contingências).
  • A é tautologia ⇔ ¬A é insatisfatível.
  • Para provar tautologia, tentem falsificá-la; se falharem, está provado.
