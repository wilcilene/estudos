Departamento de investigações lógicas

Todo argumento é uma cena de crime.

Eu organizei a disciplina como uma partida de Detetive. Vocês vão partir de pistas soltas, aprender uma linguagem sem ambiguidade, cruzar informações em tabelas-verdade, demonstrar conclusões passo a passo e, no fim, ensinar uma máquina a fechar o caso sozinha, em lógica proposicional e em lógica de predicados.

Como estudar com este guia

O jogo

Por que Detetive?

No Detetive, um suspeito, uma arma e um local estão escondidos no envelope. Cada rodada traz pistas, e só acusa quem consegue provar a resposta. É exatamente o que a lógica faz: tirar conclusões garantidas a partir de informações parciais.

Cada caso

Como os casos são montados

Todo caso começa com os objetivos, explica o conteúdo com exemplos do jogo, aponta um erro comum, propõe exercícios com resposta e fecha com um resumo “Para guardar”.
