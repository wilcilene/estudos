Caso Nº 16 · Resolução e Aspectos Computacionais

Algoritmo de Resolução Proposicional

É hora de automatizar o investigador: um algoritmo que recebe um conjunto de cláusulas e busca, sozinho, a contradição que fecha o caso.

Ideia geral do algoritmo

O algoritmo de resolução parte de um conjunto de cláusulas (a base de conhecimento, já incluindo a negação da conclusão que se quer provar) e aplica a regra de resolução repetidamente sobre pares de cláusulas, adicionando cada nova resolvente ao conjunto, até que aconteça uma de duas coisas: surge a cláusula vazia (contradição encontrada — a conclusão está provada) ou nenhuma resolvente nova pode ser gerada (a conclusão não decorre das premissas).

Passo a passo

Pseudocódigo 
função resolucao(clausulas):
    enquanto verdadeiro:
        novas = conjunto vazio
        para cada par (C1, C2) em clausulas:
            resolventes = resolver(C1, C2)
            se cláusula vazia estiver em resolventes:
                retorna "contradição encontrada — conclusão provada"
            novas = novas ∪ resolventes
        se novas ⊆ clausulas:
            retorna "nenhuma contradição — conclusão não provada"
        clausulas = clausulas ∪ novas

A cada rodada, o algoritmo tenta resolver todos os pares de cláusulas disponíveis; se nenhuma cláusula nova surgir, é sinal de que já exploramos tudo o que era possível derivar — e a busca termina.

Resolvendo o caso automaticamente

Conjunto de cláusulas: {p, q}, {¬p}, {¬q}.

  1. Resolver {p, q} com {¬p} → resolvente {q}.
  2. Resolver {q} com {¬q} → resolvente { } — cláusula vazia!

A contradição confirma que o conjunto original era insatisfazível — se essas cláusulas incluíam a negação de uma acusação, o algoritmo acabou de provar, sem intervenção humana, que a acusação estava correta.

Exercício

Trace os passos do algoritmo para o conjunto {p}, {¬p, q}, {¬q}.

Ver resposta

1. Resolver {p} com {¬p, q} → {q}.
2. Resolver {q} com {¬q} → { } — cláusula vazia, contradição encontrada.
