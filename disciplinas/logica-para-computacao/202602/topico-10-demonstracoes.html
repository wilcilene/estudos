Demonstrações em Lógica Proposicional

Uma demonstração formal é o relatório final do investigador: cada linha, justificada por uma regra, até a conclusão que fecha o caso sem margem para dúvida.

Estrutura de uma demonstração

Uma demonstração (ou prova) formal é uma sequência numerada de fórmulas, em que cada linha é ou uma premissa dada, ou o resultado de aplicar uma regra de inferência a linhas anteriores. A última linha é a conclusão que se queria provar. Cada linha deve trazer sua justificativa explícita.

Estratégias de demonstração

  • Prova direta: aplicar regras de inferência às premissas até alcançar a conclusão.
  • Prova por contradição (redução ao absurdo): assumir a negação da conclusão e mostrar que isso leva a uma contradição — logo, a conclusão original deve ser verdadeira.
  • Dedução condicional: para provar p → q, assume-se p como hipótese adicional e deriva-se q a partir dela.

Demonstração completa do caso

Dossiê final

Premissas: (1) P → M, (2) M → C, (3) P. Objetivo: provar C.

1. P → M         (premissa)
2. M → C         (premissa)
3. P             (premissa)
4. P → C         (silogismo hipotético, 1 e 2)
5. C             (modus ponens, 4 e 3)

Cada linha é justificada por uma regra aplicada a linhas anteriores — não há espaço para "achismo": a conclusão C é inevitável a partir das premissas aceitas.

Por que formalizar em vez de "só saber"

Uma demonstração formal permite que qualquer pessoa — ou qualquer programa — verifique mecanicamente se um argumento é correto, sem precisar confiar na intuição de quem o escreveu. Essa verificabilidade é o que torna a lógica proposicional a base de assistentes de prova e de verificadores automáticos de software.

Exercício

Complete a demonstração: premissas (1) ¬C → ¬P, (2) P. Qual regra permite concluir C diretamente?

Ver resposta

Modus tollens aplicado à contrapositiva: de ¬C → ¬P e P (equivalente a ¬¬P), deriva-se ¬¬C, ou seja, C após eliminar a dupla negação.
