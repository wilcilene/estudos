Linguagem Formal e Símbolos Lógicos

Antes de montar fórmulas, o investigador precisa conhecer o alfabeto da lógica: os símbolos e as regras que dizem exatamente o que conta como uma expressão válida.

O alfabeto da lógica proposicional

Toda linguagem formal começa com um conjunto fechado de símbolos. Na lógica proposicional, o alfabeto tem três partes:

  • Variáveis proposicionais: p, q, r, s, ... — representam proposições atômicas.
  • Conectivos lógicos: ¬, ∧, ∨, →, ↔ — combinam ou modificam proposições.
  • Símbolos auxiliares: ( ) — parênteses, usados para eliminar ambiguidade.

Regras de formação: o que é uma fórmula bem formada

Nem toda sequência de símbolos é uma fórmula válida. Uma fórmula bem formada (FBF) segue uma definição recursiva:

  1. Toda variável proposicional isolada (p, q...) é uma FBF.
  2. Se A é uma FBF, então ¬A também é.
  3. Se A e B são FBFs, então (A ∧ B), (A ∨ B), (A → B) e (A ↔ B) também são.
  4. Nada mais é uma FBF.

Essa definição "por camadas" é o que permite construir fórmulas arbitrariamente complexas a partir de peças simples — e também é o que permite a um programa verificar automaticamente se uma expressão é válida.

Representando o caso

Imagine os símbolos B: "o crime ocorreu na biblioteca", M: "o mordomo é culpado" e F: "a faca foi usada". A frase "se o crime ocorreu na biblioteca e o mordomo é culpado, então a faca foi usada" vira a FBF ((B ∧ M) → F). Cada suspeito, arma e local do caso pode virar um símbolo — e cada pista, uma fórmula.

Por que os parênteses importam

Sem parênteses, uma expressão como p ∧ q ∨ r seria ambígua: significa (p ∧ q) ∨ r ou p ∧ (q ∨ r)? Essas duas fórmulas podem ter valores-verdade diferentes. Por isso, a definição formal exige parênteses sempre que dois conectivos binários se encontram — embora, na prática, adotemos convenções de precedência (vistas no próximo caso) para escrever com menos parênteses sem perder precisão.

Exercício

Quais das expressões abaixo são fórmulas bem formadas, segundo as regras de formação?

  1. (p ∧ q)
  2. p ∧ ∧ q
  3. ¬(p → q)
  4. (p ∨ )
Ver resposta

1. FBF válida.
2. Não é FBF — dois conectivos binários seguidos, sem uma FBF entre eles.
3. FBF válida — negação aplicada a uma FBF entre parênteses.
4. Não é FBF — falta a segunda subfórmula do conectivo ∨.
