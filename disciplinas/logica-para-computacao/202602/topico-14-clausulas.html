Caso Nº 14 · Princípio da Resolução

Cláusulas e Representação por Conjuntos

Uma vez em forma normal conjuntiva, cada pista vira uma cláusula — e o caso inteiro, um conjunto de cláusulas prontas para serem cruzadas.

O que é uma cláusula

Uma cláusula é uma disjunção de literais, onde um literal é uma variável proposicional ou sua negação (p ou ¬p). Em vez de escrevê-la com o símbolo ∨, é comum representá-la simplesmente como um conjunto de literais — já que a ordem e a repetição não importam em uma disjunção.

Por exemplo, a cláusula (p ∨ ¬q ∨ r) pode ser escrita como o conjunto {p, ¬q, r}.

De FNC para conjunto de cláusulas

Como uma fórmula em FNC é uma conjunção de cláusulas, e a conjunção exige que todas sejam verdadeiras simultaneamente, podemos representar a fórmula inteira como um conjunto de conjuntos de literais — cada cláusula precisa ser satisfeita, mas a ordem entre cláusulas não importa.

Representando pistas como cláusulas

A fórmula (p ∨ r) ∧ (q ∨ r) ∧ (¬p ∨ ¬q) vira o conjunto de cláusulas:

{ {p, r}, {q, r}, {¬p, ¬q} }

Cada chave { } interna é uma pista independente que precisa ser respeitada; juntas, elas formam o dossiê completo do caso, pronto para ser processado por um algoritmo de resolução.

Cláusula vazia e cláusula unitária

Dois casos especiais merecem atenção. Uma cláusula unitária tem um único literal, como {p} — equivale a afirmar p diretamente, sem alternativas. Uma cláusula vazia, { }, não tem literal algum que possa satisfazê-la — ela representa uma contradição, e sua aparição durante uma resolução é o sinal de que o caso foi resolvido por refutação, como veremos a seguir.

Exercício

Escreva o conjunto de cláusulas correspondente à FNC (¬p ∨ q) ∧ (¬q ∨ p) ∧ p.

Ver resposta

{ {¬p, q}, {¬q, p}, {p} } — note que a última é uma cláusula unitária.
