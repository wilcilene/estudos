Modelagem na prática

Uma ferramenta, dois sentidos

A partir do diagrama de classes, a disciplina explora a Astah como apoio à modelagem.

Do diagrama para o código

Depois de modelar classes, atributos, métodos e relacionamentos, a Astah gera automaticamente a estrutura de projeto e as classes correspondentes — economizando a digitação do "esqueleto" do código.

Do código para o diagrama (engenharia reversa)

O caminho inverso também é possível: a partir de um código-fonte já existente, a ferramenta reconstrói o diagrama de classes correspondente — útil para entender ou documentar um sistema legado.
